# 주간 업무 회고 (5월 1주차)

## 1. 주요 업무 성과 (Key Achievements)

CRM 베타테스트 고도화 및 5월 12일 공식 릴리스 준비 완료, 메인 홈페이지 UI/데이터 현행화 진행

- **CRM 시스템: 베타테스트 마감 및 릴리스 고도화**
    
    - **당사자 및 관계자 관리 UI/UX 개선:**
        
        - 신규 당사자 등록 시 불필요한 태그 선택 영역 숨김 처리로 입력 화면 간소화
            
        - 관계자 선택 시 단순 요약 데이터가 아닌 당사자 키(Key) 기준으로 실제 상세 정보를 조회하도록 데이터 맵핑 정확도 향상
            
    - **구글 캘린더 연동 및 동기화 강화:**
        
        - 상담 상태 '취소' 변경 시 캘린더 이벤트 색상 빨간색 자동 지정 및 상태 복구 시 기본값 롤백 기능 구현
            
        - 상담 등록/일정 수정 시 상태값 변경이 캘린더에 즉각 반영되도록 데이터 흐름 개선
            
    - **문자 발송 시스템(NCP) 권한 및 로직 고도화:**
        
        - 지사별(인천·부천 / 수원·남양주) 발신번호 매핑 추가로 선택 범위 확대
            
        - 소속 지사 권한 범위 검증 로직 추가 및 서버 허가 발신번호 목록만 노출되도록 보안성 강화
            
    - **공식 배포 준비:**
        
        - 5/12 CRM 공식 릴리스 배포용 발표 스크립트 작성 완료
            
- **메인 법승 홈페이지: 프론트엔드 개선 및 콘텐츠 현행화**
    
    - **UI/UX 및 화면 동선 개선:**
        
        - 센터 메뉴 진입 시 빈 화면 노출 버그 수정 및 '회생 안내' 화면으로 즉시 이동하도록 라우팅 동선 개선
            
        - 지역 메인 화면 내 공휴일 상담 안내 팝업 추가(딤 처리, 하루 안 보기 등) 및 연휴 종료 후 비활성화(주석 처리) 완료
            
    - **인사 변동 및 SEO 데이터 현행화:**
        
        - 퇴사 변호사(김경호, 노현정) 메인 화면 롤링 카드 노출 제거
            
        - 지역 구조화 데이터 내 퇴사 변호사 항목 삭제 조치로 검색 엔진 최적화(SEO) 반영
            

## 2. 기술적 도전 및 트러블슈팅 (Technical Challenges & Troubleshooting)

- **관계자 상세 데이터 정합성 보장 및 렌더링 최적화:** 동일한 상세 화면 내에서 다른 관계자를 클릭할 때 기존 데이터가 잔존하는 이슈가 있었음. 당사자 키(Key) 경로 기반 라우팅으로 구조를 변경하여 상담, 문자, 관계 목록 데이터가 정상적으로 갱신(새로고침)되도록 프론트엔드 상태 관리 로직을 수정함.
    
- **신규 당사자 등록 페이로드 최적화:** 신규 등록 과정에서 불필요한 태그 목록과 색상 데이터가 백엔드로 전송되는 오버헤드를 확인. 데이터 전송 로직을 분리하여 불필요한 페이로드 발생을 차단함 (기존 수정 화면의 기능은 영향 없도록 캡슐화 유지).
    
- **테스트 환경 도메인 리다이렉트 예외 처리:** 실서버에 적용된 `www` 강제 리다이렉트 규칙이 테스트 도메인에도 영향을 미쳐 접근이 제한되는 문제를 파악. 테스트 도메인 접속 시에는 해당 리다이렉트가 동작하지 않도록 인프라/서버 설정에 예외 조건을 추가하여 테스트 환경 안정성을 확보함.
