# 주간 업무 회고 (5월 3주차)

## 1. 주요 업무 성과 (Key Achievements)

CRM 시스템의 연속 릴리즈(v1.0.3~v1.0.5) 및 차세대 홈페이지(v2)의 모노레포 아키텍처·대규모 DB 마이그레이션 성공

- **CRM 시스템**: v1.0.3 ~ v1.0.5 연속 릴리즈 및 양방향 데이터 파이프라인 구축
    
    - **UI/UX 및 프론트엔드 개선**:
        
        - 모바일 상태 필터 가로 스크롤 적용 및 회생 상담일지 결과 화면 PNG 저장(위젯 기반) 기능 구현
            
        - 단체 문자 수신 다건 동적 리스트 구현 및 발송 정보 패널 UI 개선
            
        - 문자 발송 시 PDF 첨부 기능 추가 및 파일 선택기(file_picker) 플러그인 의존성 제거로 초기화 오류 해결
            
        - 당사자 목록 내 메모 수정 시 즉각적인 화면 반영 및 회생팀 전용 메뉴 권한(organization_key) 필터링 적용
            
    - **백엔드 및 데이터 연동**:
        
        - 당사자 상세 페이지 URL 라우팅을 식별 키(partyKey) 기반으로 단순화 및 로딩 구조 전면 개편
            
        - 담당자 상담 구글 시트 ↔ Cloud DB 간 웹훅(Webhook) 및 Upsert 기반 양방향 데이터 동기화 파이프라인 구축
            
        - 단체 문자 다건 전송 백엔드 처리 및 실패 건 개별 이력 기록 등 예외 처리 강화
            
        - 상담 일정 종료 시간 직접 입력 기능 신설 및 구글 캘린더 양방향 연동
            
- **메인 홈페이지 리뉴얼 (v2)**: Next.js/NestJS 모노레포 구축 및 DB 마이그레이션
    
    - **인프라 및 백엔드**:
        
        - Turborepo 기반 프론트/백엔드 뼈대 구축 및 기존 SQL Server에서 PostgreSQL로 730만 건의 데이터 이관 완료
            
        - 기존 12개로 분리된 지역별 URL 구조를 단일 메인 라우트로 통합
            
        - 게시판, 약관, 상담, 변호사 조회를 위한 NestJS 기반 신규 API 구축 및 실데이터 연동
            
    - **UI/UX 전면 개편**:
        
        - 19개 주요 서브 페이지 라우트 생성 및 변호사 상세 프로필을 해외 로펌 스타일로 개편
            
        - 인터랙티브 한반도 지도 애니메이션 적용 및 모든 대표 전화상담 버튼을 '지점별 번호 선택 팝오버'로 통합
            
        - 홈 화면에 동적 애니메이션(Aurora, Marquee) 및 스크롤 기반 도트 내비게이션, 플로팅 위젯 부착
            
- **사내 보안 및 마케팅 인프라**: 시스템 보안 설계 및 데이터 추적 고도화
    
    - **사내 보안 인프라 (ACP 클라우드)**: 클라이언트 측 암호화(CSE) 및 외부 키 관리(EKM)를 결합한 사법 방어선 설계 완료 및 9월 라이선스 연계 로드맵 수립
        
    - **법승 메인 홈페이지 (기존)**: 회생 및 서울 지역 페이지 내 네이버 공통 스크립트(WCS) 설치 및 맞춤형 전환(Lead, Schedule) 지표 세분화 추적 적용
        

## 2. 기술적 도전 및 트러블슈팅 (Technical Challenges & Troubleshooting)

- **크로스플랫폼 빌드 형상 관리 충돌 해결**: 윈도우 OS와 자동 생성 플러그인 파일 간 줄바꿈(LF/CRLF) 차이로 인해 불필요한 가짜 변경 기록이 발생하는 문제를 확인함. Flutter 자동 생성 폴더의 줄바꿈 방식을 LF로 명시 지정하고 `.gitignore` 설정을 업데이트하여 빌드 환경을 안정화함.
    
- **데이터 정합성 및 무중단 마이그레이션 확보**: 상담 목록의 등록 일시를 UTC에서 로컬 시간으로 변환하여 결과 화면 및 PDF 출력 시의 시간 정합성을 맞춤. 또한 CRM 일정 테이블에 신규 컬럼을 추가할 때, 이미 존재할 경우 건너뛰는 멱등성(Idempotent) 마이그레이션 스크립트를 작성하여 DB 충돌을 방지함.
    
- **레거시 시스템 500 오류 리스크 선제 대응**: 기존 운영 중인 백엔드 시스템에서 500.30 및 500.31 오류 발생 리스크를 식별함. 무리한 코드 수정 시 서비스 장애로 이어질 수 있다고 판단하여, 레거시 시스템의 수정을 잠정 중단하고 현재 순항 중인 신규 리뉴얼(v2) 프로젝트에 개발 역량을 집중하는 것으로 개발 전략을 유연하게 조정함.
    

## 3. 총평 및 향후 과제 (Wrap-up & Next Steps)

> **"공격적인 CRM 기능 릴리즈와 차세대 홈페이지의 성공적인 뼈대 구축으로 실무 효율과 서비스 품질을 동시에 끌어올린 한 주"**

이번 주 CRM 시스템은 단체 문자 발송, 캘린더 연동, 양방향 데이터 동기화를 포함한 3차례의 업데이트(v1.0.3~v1.0.5)를 통해 실무자의 업무 생산성을 크게 향상시켰습니다. 동시에 차세대 홈페이지 리뉴얼(v2)을 위한 모노레포 구축과 730만 건의 DB 마이그레이션을 안정적으로 완수하며, 현대화된 서비스 환경으로 도약하기 위한 강력한 기술적 기반을 마련했습니다.

- **ACP 클라우드 암호화 시스템 구축 착수**: 6월 초 기한인 대표 변호사 최종 승인 직후, EKM 게이트웨이 외주 발주 및 사내 응용 프로그램 개발 실무 돌입

- **마케팅 전환 데이터 모니터링**: 메인 홈페이지에 설치된 전환 추적 스크립트가 리드 및 예약 데이터를 정확히 수집하고 있는지 모니터링 및 검증
