캡처가 보여주는 것은 화면 구조와 확인한 클라이언트 상호작용입니다. 운영 인증·DB 저장·외부 업로드·문자 발송·실제 퇴직 예약 실행 성공을 증명하는 자료로 쓰지 않습니다. 계정·글 저장·결재 처리는 운영 서비스에 제출하지 않았습니다. CMS의 모의 저장 오류와 CRM의 샘플 초안 복원은 각 manifest의 확인 범위로 별도 기록했습니다.

정확한 소스 HEAD, 재사용 컴포넌트, 작업본 수정, URL, 캡처 영역, 실행 명령과 확인 결과는 `../../../경력기술서/검토/캡처근거/`의 `portal.json`, `cms.json`, `crm.json`, `case.json`에 있습니다. 회사 원본 HEAD가 작업 중 변경된 경우에도 캡처는 처음 고정한 worktree 소스에서 실행했습니다.
