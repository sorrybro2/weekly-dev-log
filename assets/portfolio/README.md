# 포트폴리오 이미지

제공된 증명사진 `profile.jpg`를 첫 페이지에 원본 3:4 비율, 32×42.67mm로 표시하고 HTML/PDF에 내장합니다.

`homepage.png`, `crm.png`, `case-management.png`는 실제 서비스 캡처입니다. 회사 이름·도메인은
그대로 노출되어도 되지만, 의뢰인을 특정할 수 있는 당사자명·연락처·사건 내용은 검색창에
"테스트"를 입력하거나 직접 가려서 촬영합니다. 이미지 속 글자는 자동 익명화되지 않으므로
새 캡처를 추가할 때도 같은 기준으로 가려야 합니다. 캡처가 없는 프로젝트는 각 프로젝트의
실제 구현 업무 흐름을 HTML/CSS 도식으로 대신 표시합니다.

자세한 캡처 범위와 출력 방법은 [편집 가이드](../../portfolio/README.md)를 참고하세요.
