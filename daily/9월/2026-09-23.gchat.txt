AI 상담봇의 검색부터 상담 접수까지 연결하고 운영 준비 과정의 장애를 진단했습니다. 추석 공지와 레거시 이미지 누락 대응도 구현했습니다. 금일 커밋 26건(홈페이지 V2).

💬 *〔AI 상담봇 구현〕*

•  *대화 처리* — 검색:답변 생성:출력 검사:저장을 백엔드 요청 하나로 연결 (04234c2, 4f88ff4, 867dfe7)
•  *실제 응답 오류* — 스트리밍 줄바꿈 차이로 답변이 비던 문제와 모듈 누락으로 서버가 안 뜨던 문제 수정 (01a2df5, acefe74)
•  *화면 연결* — PC:모바일 런처와 패널, 작성 중 표시, 상담 안내 전환 구현 (5cc1858, df18a21)
•  *상담 접수* — 분야별 질문과 긴급 전화 안내, 동의 기반 접수 폼을 대화에 연결 (8fe22d0)
•  *맥락과 지점* — 이전 사연을 검색에 반영하고 지점을 확정해 잘못된 분야:본사 안내를 줄임 (7340482, 9411a3f)
•  *근거 카드* — 담당 변호사:사무소를 표시하고 관련성이 약하거나 중복된 사례 노출을 줄임 (4a33e30, 40933db)

🛡 *〔출력 안전장치와 사용 한도〕*

•  *출력 검사* — 금지 표현은 전송 전에 검사하고, 잘린 주소 때문에 정상 답변까지 막히던 오판 수정 (838e1df, 6dc14fe)
•  *재시도 제한* — 시간 예산 안에서만 재시도하고 실패하면 상담 접수 안내로 전환 (5282276)
•  *남용 대응* — 세션:IP:전역 한도와 한도 임박:도달 운영 알림 적용 (d48bf9c, 6d7f9da, 838e1df)

🚀 *〔운영 준비와 장애 진단〕*

•  *운영 DB* — 상담봇 테이블 적용 누락을 실제 요청에서 확인하고 테이블:컬럼 적용 완료 기록 확인 (이슈 125번)
•  *리전 가용성* — 서울 생성 요청의 간헐적 429를 다른 지역과 비교하고 주기 측정 시작 (ab0b69b, 이슈 125번)
•  *장문 색인* — 문장 부호 없는 긴 글이 임베딩 상한을 넘던 문제를 추가 분할로 수정 (b9465ce)
•  *출시 절차* — 운영 DB:색인:실제 응답 확인 후 화면을 배포하도록 문서화, 최종 운영 노출 완료는 미확인 (955d370, daee05a)

🌐 *〔추석 안내와 이미지 복구〕*

•  *추석 공지* — KST 기간 자동 노출과 헤더 여백 보정 구현, 최종 운영 노출 완료는 미확인 (42ece62, 이슈 136번)
