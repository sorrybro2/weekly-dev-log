#### 🔒 보안 강화

**권한 없는 어드민에게 상담 개인정보 마스킹(PII)** — `frontend/src/app/(admin)/admin/(dashboard)/contact/actions.ts`, `frontend/src/lib/pii-mask.ts`
- 어드민 상담 화면에서 모든 관리자에게 성명·연락처 등 개인정보가 원문 노출되던 문제를, **권한이 없는 어드민에게는 마스킹**해 노출 범위를 최소화. (`8bc427f`)

**전역 보안 응답 헤더 추가** — `frontend/next.config.ts`
- 클릭재킹·MIME 스니핑 등 기본 위협에 대응하기 위해 **전역 보안 응답 헤더**를 추가. (`be6ad0d`)

**상담 접수 IP 기반 빈도 제한** — `backend/src/app.module.ts`, `consult/consult.controller.ts`, `backend/src/main.ts`, `backend/package.json`

**상담 폼 reCAPTCHA v3 봇 차단** — `frontend/src/features/consult/api.ts`, `backend/src/consult/consult.service.ts`, `consult/dto/create-consult.dto.ts`, `cloudbuild.frontend.yaml`, `frontend/Dockerfile`, `.env.example`
- 자동화 봇의 상담 폼 제출을 막기 위해 **reCAPTCHA v3 봇 차단**을 프론트·백엔드에 도입하고 빌드 구성을 반영. (`d2614b4`)

**어드민 로그인 Google 전용 전환** — `frontend/src/app/(admin)/admin/login/login-form.tsx`
- 어드민 로그인의 이메일/비밀번호 폼을 제거해 **Google 전용 로그인**으로 일원화, 인증 경로를 단순화하고 자체 비밀번호 관리 위험을 제거. (`7203bdd`)

#### 🔎 SEO · 구조화 데이터 강화

### 2. CRM (고객관계관리 시스템)

#### 📥 홈페이지 접수 PostgreSQL 포팅

**접수 기능 PG 포팅** — `backend/migrations/create_hp_request_table_pg.sql`, `backend/scripts/ensure-hp-request-pg.js`, `backend/src/services/hpRequestService.js`
- 홈페이지 상담 접수 기능이 MySQL 전제로 작성되어 PG 전환 후 동작하지 않던 문제를, **PostgreSQL에서 동작하도록 포팅**(테이블 DDL·보장 스크립트 포함). (`475bda0`, 브랜치 병합 `a655afd`)
- 접수 대기 뱃지가 점유(등록 진입) 시에도 줄어들어 실제 대기 건수와 어긋나던 문제를, **무시/처리완료 시에만 줄도록** 카운트 로직을 수정. (`c4fe195`)

#### 📝 회생 폼

- **유입경로 메모 상시 입력** — `frontend/lib/pages/recovery/recovery_intake_form_screen.dart`: 특정 선택지에서만 가능하던 유입경로 추가 메모를 모든 선택지에서 상시 입력 가능하도록 개선. (`d9d586e`)
- **회생 PDF·이미지 민감 항목 제외** — `frontend/lib/pages/recovery/services/recovery_intake_pdf_service.dart`, `widgets/recovery_intake_png_renderer.dart`: 회생 상담 PDF·이미지 출력에서 유입경로·현재상태·상담메모를 제외해 외부 공유 시 민감 정보 노출을 방지. (`5fb81c2`)
