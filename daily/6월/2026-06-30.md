## 📝 상세 업무 내역

### 1. 법무법인 홈페이지 V2 리뉴얼

#### 📺 뉴스 · 미디어 영역 최적화

**YouTube 동영상 연동 방식 전환 및 안정화** — `frontend/src/features/youtube/api.ts`
- 기존 RSS 피드 방식은 데이터센터(서버) IP에서 구글에 의해 차단되어, 운영 환경의 동영상 탭이 간헐적으로 통째로 비는 문제가 있었음.
- 동영상 목록 조회를 **YouTube Data API 우선 호출**로 개편하고, API 통신 지연·실패·쿼터 초과 시에만 **RSS로 우회(Fallback)** 하는 2단 재시도 로직을 적용해 가용성을 확보. (커밋 `07a9eca`, 빈 탭 보강 `e0b22fc`)
- Data API 응답의 제목·설명에 포함된 **HTML 엔티티(`&amp;`, `&#39;` 등)가 화면에 그대로 노출되던 디코딩 오류**를 수정. (`c39c89d`)

**동영상 탭 UI·사용성 보강** — `frontend/src/components/news/news-section.tsx`
- '전체 영상' **페이지네이션**을 추가하고, 탭 상단에 **법승TV 채널 구독 버튼 및 안내 문구**를 배치해 채널 유입 동선을 마련. (`1c2aa4e`)

**뉴스 영역 URL 구조 경로 기반 전환 (SEO)** — `(site)/news/*`, `lib/news-tabs.ts`, `components/layout/site-nav-data.ts`, `sitemap_content.xml/route.ts`
- 기존 쿼리 파라미터 방식(`/news?tk=4`)을 **경로 기반 URL**(`/news/media`, `/news/notice`, `/news/social`, `/news/video`)로 분리.
- 각 탭에 **고유 메타데이터**를 부여하고 동적 사이트맵에 반영해, 검색엔진 색인·소셜 공유 시 탭별로 정확히 노출되도록 개선. 네비게이션 데이터와 홈 진입 링크도 신규 경로에 맞춰 일괄 정비. (`9521c1d`)

**어드민 운영 간소화** — `(admin)/admin/(dashboard)/bbs/constants.ts`
- 동영상이 YouTube 연동으로 자동 노출되면서 불필요해진 **미디어 관리의 '동영상' 수기 관리 탭을 제거**, 관리자 혼선을 줄임. (`0df453e`)

#### ⚖️ 승소 사례 영역

**변호사 프로필 이미지 보정** — `backend/src/bbs/bbs.service.ts`
- 사례 데이터에는 작성 시점의 변호사 이미지 경로가 스냅샷으로 박제되어 있어, 변호사가 사진을 교체하면 **삭제된 옛 경로를 참조해 프로필 사진이 깨지던 버그**가 있었음.
- 목록 카드(`fb351f2`)와 상세 페이지(`b4c049f`) 모두에서, 스냅샷 경로 대신 **현재 `tbl_lawyer`의 프로필 이미지로 덮어쓰는 보정 로직**을 적용·공통화해 깨짐을 해소.

**목록 복귀 UX 개선** — `frontend/src/components/bbs/back-button.tsx`, `bbs-detail-view.tsx`
- 사례 상세에서 목록으로 돌아갈 때, 사용자가 선택해 둔 **카테고리·페이지·검색어 상태가 초기화되던 문제**를 수정. 이전 목록의 쿼리 상태를 보존해 그대로 복귀하도록 개선. (`acab669`)

#### 🖥️ 어드민 — 카테고리 관리 개선

**상담 신청 폼 reCAPTCHA 연동 및 검증 강화**
- 프론트엔드(`consult-form.tsx`, `features/consult/api.ts`, `cloudbuild.frontend.yaml`): 운영용 reCAPTCHA v3 사이트키를 연결하고, 폼 진입 시 **스크립트를 사전 로드(preload)** 해 제출 시 지연을 최소화. 오류·요청 빈도 제한(429) 발생 시 **사용자에게 친절한 한글 안내 메시지**를 노출하도록 UX 보강. (`5ac2a0f`)
