## 📝 상세 업무 내역

### 1. CRM (고객관계관리 시스템)

#### 🐘 MySQL → PostgreSQL 마이그레이션 (금일 핵심)

**DB 드라이버 교체 및 호환 래퍼** — `backend/src/models/db.js`, `backend/package.json`
- 운영 DB를 MySQL에서 PostgreSQL로 이전하기 위해, 먼저 **DB 드라이버를 PostgreSQL로 교체**하고 기존 코드가 그대로 동작하도록 `db.js` 호환 래퍼를 두어 스모크 테스트 통과까지 확인. (`84d08c9`, 기록 `2978dc0`, `1026490`)

**SQL 방언 단계적 변환** — `backend/src/controllers/*`, `backend/src/services/*`, `backend/src/jobs/*`
- MySQL 전용 문법이 다수 남아 PG에서 동작하지 않는 문제를, **여러 차수로 나눠 체계적으로 변환**.
  - 1차: 함수·날짜·따옴표 변환 (`894b3bd`)
  - 2차: UPSERT·락·대소문자 처리 변환 (`5b7c97d`)
  - `LIMIT offset,count` → `OFFSET/LIMIT`, 회생 다운로드의 백틱 별칭 제거 (`432f88b`)
  - 런타임 introspection의 `DATABASE()`를 `current_schema()`로 변환 (`cecfc82`)
- 변환 범위·실측 건수와 Phase 3 검증 결과를 계획 문서에 기록. (`03db6bf`, `4ae017e`)

**데이터 마이그레이터 및 증분 동기화 스크립트** — `backend/scripts/migrate-mysql-to-postgres.js`, `sync-mysql-to-postgres-upsert.js`, `check-pg-schema.js`
- 실제 데이터 이관을 위한 **MySQL→PostgreSQL 데이터 마이그레이터**를 추가하고(`20b8a5a`), 컬럼 DEFAULT까지 PG로 이관되도록 보완. (`dae5bfb`)
- 컷오버 시점의 최신 데이터를 반영하기 위한 **증분 UPSERT 동기화 스크립트**를 추가하고 컷오버 런북에 반영. (`58e7a00`)
- 부팅 체인을 정비해 **prestart를 MySQL 마이그레이션 실행 대신 PG 스키마 확인**으로 교체. (`a9577a4`, Phase 4 기록 `6cc63b5`)

**구글 연동 스키마 정합** — `backend/src/services/googlePeopleContactService.js`, `employeeAdminEmpInfoSyncService.js`, `employeeMasterSyncService.js`, `googleDirectorySyncService.js`
- 구글 연동 코드가 참조하던 `google_oauth_token` 컬럼명이 실제 PG 스키마(email/scope)와 어긋나던 문제를 스키마에 맞춰 수정. (`d94b6ee`, 기록 `6e2619e`)

**컷오버 준비 및 진행 기록** — `docs/cutover-runbook.md`, `docs/mysql-to-postgresql-migration-plan.md`
- 본 서버(lawwin-crm)의 실제 값으로 **컷오버 명령을 확정**하고 런북을 정비. (`6dba57a`)
- 테스트 서버 PG 배포·검증 결과, Phase 6 읽기 엔드포인트 **QA 11/11 통과**, Phase 0·2·5·8 및 pgvector 진행 등 단계별 결과를 계획 문서에 기록. (`5a93c95`, `0396d21`, `ee553b8`, 계획 초안 `7cd788f`)
