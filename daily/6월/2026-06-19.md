## 📝 상세 업무 내역

### 1. CRM (고객관계관리 시스템)

#### 📤 추출(엑셀) 기능 고도화

**성명·전화번호 식별/비식별 선택 추출** — `backend/src/controllers/inflowDownloadController.js`, `recoveryDownloadController.js`, `frontend/lib/pages/consultation/services/inflow_download_service.dart`, `recovery/services/recovery_download_service.dart`
- 개인정보를 담은 상담·회생 데이터를 추출할 때 성명·전화번호가 항상 원문으로 나가, 공유·보관 용도에 따라 노출 위험이 있었음.
- 상담·회생 추출 다이얼로그에 **식별/비식별 선택 옵션**을 추가해, 목적에 맞게 원문 또는 마스킹 형태로 추출하도록 개선. (`be2d9b3`)

**추출 컬럼·형식 선택을 계정별로 저장** — `frontend/lib/pages/consultation/services/inflow_download_prefs.dart`, `recovery/services/recovery_download_prefs.dart`, 각 `*_download_dialog.dart`
- 매번 추출 시 컬럼·형식을 다시 지정해야 하던 번거로움을, **선택값을 계정별로 저장**해 다음 추출 때 그대로 불러오도록 개선. (상담 `1b2f8e5`, 회생 `7347ebd`)

**회생 상담관리 검색·추출 대상 일치** — `backend/src/controllers/recoveryDownloadController.js`, `recoveryIntakeController.js`
- 화면에서 보이는 검색 결과와 실제 추출 대상 범위가 어긋나던 문제를, **화면 검색 조건과 동일하게 추출 대상을 확장**해 정합성을 맞춤. (`775fb4b`)

#### 💬 문자·상담 폼 식별성 개선

- **문자 발송 수신자 라벨에 라벨메모 표시** — `frontend/lib/pages/party/utils/party_form_mappers.dart`, `sms/services/sms_form_service.dart`, `sms/sms_form_screen.dart`: 동명이인 등으로 수신자 구분이 어렵던 문제를, 라벨에 라벨메모를 병기해 해소. (`c680b65`)
- **상담 당사자 선택 드롭다운 라벨에 라벨메모 표시** — `backend/src/controllers/partyConsultationController.js`: 상담 등록 시 당사자 선택 드롭다운에도 라벨메모를 함께 노출해 오선택을 방지. (`61d8f73`)
- **회생 상담관리 여백 조정** — `frontend/lib/pages/recovery/recovery_intake_screen.dart`: 검색창과 신규 등록 버튼 사이 간격을 추가해 오클릭을 줄임. (`d2e6c4c`)

#### 🚀 배포 안정화

- **도커 빌드 버전 고정·`npm ci` 전환** — `backend/Dockerfile`: 의존성 버전이 유동적이어서 재빌드 시 로그인 등 동작이 깨지던 문제를, 버전 고정과 `npm ci` 적용으로 재현 가능한 빌드로 전환. (`83bce14`)
- **배포 명령 `--project` 명시** — `docs/cloud-run-build-rule.md`: 배포가 CLI의 활성 프로젝트 설정에 의존해 오배포 소지가 있던 점을, 명령에 `--project`를 명시하도록 문서화. (`4955cf5`)

### 2. 법무법인 홈페이지 V2 리뉴얼

#### 🗂️ 업로드 저장소 GCS 전환

**어드민 이미지 업로드를 GCS로 저장·서빙** — `backend/src/storage/gcs.storage.ts`, `storage/storage.module.ts`, `frontend/next.config.ts`
- 어드민 업로드 이미지를 컨테이너 로컬 디스크에 저장하면 Cloud Run 인스턴스 교체·재배포 시 유실되는 구조적 문제가 있었음.
- 업로드 저장·서빙을 **GCS 기반으로 전환**해 인스턴스와 무관하게 영구 보관·서빙되도록 개선. (`206203f`)
- 백엔드 **Cloud Build 빌드 구성(`cloudbuild.backend.yaml`)** 을 추가해 배포 파이프라인을 정비. (`cde74aa`)
