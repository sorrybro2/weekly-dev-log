## 📝 상세 업무 내역

### 1. 사건관리 앱 — 수발신 문서대장 신규 구축

#### 🔌 백엔드 API

- **통합·단건 조회 API** — 전 사건 통합 목록 `GET /document-logs`(사무소·월·날짜범위·구분·사건·키워드 필터), 수정/직접 URL용 단건 `GET /document-logs/{id}` 추가. 응답에 사건명·담당자 이름을 조인해 반환하고 키워드 검색에 담당자 이름 매칭 포함. (`ff8cb35`)

#### 🖥️ 목록·등록/수정 화면

- **화면 신규** — 목록(필터+테이블+인라인 추가), 등록/수정(사건검색·구분토글·수발신방법 콤보박스·담당자·Drive·비고) 페이지 신설. 사건 상세 진입 시 사건 고정, 사건 선택 시 Drive 링크 자동 채움. 라우트 3개(`/document-logs`, `/new`, `/:id`) 및 공용 피커(사건검색·방법·담당자) 추가. (`8f2136e`)
- **정보실 제외** — 목록 사무소 탭·담당팀 드롭다운에서 정보실(실제 사무소 아님) 제외, 상담료 화면과 동일한 `EXCLUDED_OFFICE_KEYS` 기준 적용. (`bd0030b`)

#### 🎨 목록 UX 개선

- **추가 드로어·연속 입력** — 문서 추가를 우측 슬라이드 패널로 변경, 저장 후 사건·구분·날짜 유지한 연속 입력 지원. (`24d7568`)
- **지사 필터 수정** — `office_key`가 조직명으로 저장돼 있어 필터·생성 모두 조직명 기준으로 통일. (`24d7568`)
- **필터 유지·페이지네이션** — 지사·월·날짜범위·구분·사건 필터를 새로고침 후에도 유지(localStorage), 클라이언트 페이지네이션 12건/페이지 적용. (`24d7568`)
- **필터 카드 UI·상세 드로어** — 필터를 카드형(기간·구분 세그먼트·사건 검색·초기화)으로 정리, 지사 탭 별도 행 분리, 테이블 고정 레이아웃(colgroup)으로 컬럼 폭 정리, 행 클릭 시 우측 슬라이드 상세 드로어 표시. (`f5206e4`)

### 2. 사건관리 앱 — 상담료(상담 관리) 페이지 개편

#### 🔗 처리 대기 정비

- **노출 대상 한정** — 방문·전화(변호사)·접견 상담 일정만 처리 대기에 노출, 접수·취소·노쇼 상태는 제외. 취소·노쇼용 '처리 완료' 버튼 및 상태 필터 제거. (`95c4820`)
- **취소·노쇼 숨김** — 취소·노쇼·접수 일정에 연결된 상담료 레코드를 목록·집계에서 제외, 옛 흐름으로 생긴 빈 레코드 잔존 문제 해결. 수동 등록 상담료는 유지. (`4938179`)

#### 📅 필터·입력 UX

- **연월 드롭다운 달력** — 상단 월 선택을 텍스트 입력 없이 클릭으로 여는 달력 드롭다운으로 교체(연도 이동+12개월 그리드, 외부 클릭 시 닫힘). (`e0c79ad`)
- **지사·연월 유지** — 선택한 지사·연월을 브라우저에 저장해 새로고침·재진입 후에도 복원. (`310078a`)
- **상담자 역할 필터·금액 UX·사건명** — `/search/employees`에 role(변호사/직원) 파라미터 추가(재직만, '이름 직위' 형태만 반환), 드롭다운 분리 조회. 목록에 사건명 컬럼(연결 일정 또는 수임 계약 title), 금액 천 단위 콤마 표시, 납부금액 기본값=상담료 자동 동기화. (`50a615a`)

#### 🎨 레이아웃

- **UI 개선** — 목록/처리 대기를 테두리·헤더 카드로 분리, 배지 채도·대비 상향, 1500px 기준 반응형(이상 2단 동시/미만 탭), 처리 대기 입력 시 새 행 강조·좁은 화면 자동 탭 전환, 수임전환 컬럼 제거. (`8dd6858`)
- **의존성** — 병합된 `@base-ui/react` 도입에 맞춰 lockfile 동기화(설치 시 불일치로 개발 서버 실패하던 문제 해소). (`7a61132`)

### 3. 사건관리 앱 — 계약 상세 패널 개선

- **폴더트리·수납내역·도과 로직** — 상세 패널 하단에 폴더 구조 트리 추가(URL 있으면 링크, 없으면 회색), 수납 내역 테이블 정비(회차→차수·가운데 정렬), 도과 상태를 납부일 vs 납부예정일 비교로 변경, 발송 모달 미리보기 전체 표시. (`ea0ae33`)
- **`drive_folder_url` 누락 수정** — 백엔드 Pydantic 스키마·프론트 타입에서 필드가 빠져 SQL 조회 결과가 응답에서 제거되던(폴더트리 회색) 문제 수정. (`4408c17`)

### 4. CRM (고객관계관리 시스템)

- **당사자 시트 동기화 성능·복구** — 당사자 생성·수정·삭제 시 응답 전 동기 await로 ~36초 지연되던 구글시트 동기화를 응답 후 백그라운드 실행으로 전환. 수정·삭제에서 제거됐던 CRM→시트 미러링을 복구해 완전 양방향 유지, 공용 헬퍼 추가·실패는 서버 로그로만 기록. (`e013edf`)
