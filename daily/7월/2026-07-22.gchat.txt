📱 *1. 반응형 대응 (이슈 28) : 목록 6종 모바일 카드 전환*

배경: 앞서 목록들에 반응형을 입혔지만 좁은 화면에서 표가 여전히 가로로 넘쳐 답답했다. '컬럼을 숨기는' 접근 대신 모바일에서는 표 자체를 세로 카드 리스트로 교체해 가로 스크롤을 없애고 한눈에 들어오게 했다. 기존 CaseListMobile 카드 패턴과 톤을 맞췄다.
 •  *공통 DataTable 카드 모드 + 공용 카드 셸* — DataTable에 renderMobileCard prop을 추가해 모바일에서 표 대신 카드 리스트를 그리게 하고(필터:페이지네이션:합계바 유지), 6개 화면이 공유하는 3줄 구조 카드 셸 MobileListCard(제목+뱃지 : 부가정보 : 강조값+메타)를 신설. 카드 미제공 표를 위한 meta.mobileHidden 폴백도 함께. (c6fe47c)
 •  *DataTable 4종 카드 전환* — 계약(49b4402):미수금(3c53a18):상담료(665c6e3):열람등사(82899f2) 각 화면에 페이지 성격에 맞는 카드 렌더 연결.
 •  *자체 표 2종 카드 전환* — CSS-grid 표인 법원진행내역(99f935e)과 table 기반 수발신문서를 각각 모바일 분기해 카드로 렌더. 수발신문서는 페이지당 카드 수를 카드 높이(96px) 기준으로 자동 계산하도록 페이지네이션 보정. (b92187d)

🧩 *2. 컬럼 설정 UX 통일 : 손수 만든 표를 표준에 맞춤*

배경: DataTable 4종은 컬럼 드롭다운(표시:숨김:순서:초기화)을 갖췄지만 손수 만든 수발신문서:법원진행내역은 순서변경 토글만 있거나 항상 드래그되는 헤더라 동떨어져 있었다. 셋을 하나의 UX로 통일했다.
 •  *컬럼 상태 훅 확장 + 공용 드롭다운 신설* — useColumnResize에 컬럼 표시:숨김(hidden:toggleColumn:visibleOrder)과 전체 초기화(resetAll)를 추가하고 localStorage에 영속. 손수 만든 표용 컬럼 설정 드롭다운 ColumnControlMenu(순서변경:초기화:표시할 열)를 신설. (7216005)
 •  *수발신문서 컬럼 메뉴 적용* — 기존 순서변경 토글 버튼을 컬럼 드롭다운으로 교체해 표시:숨김까지 지원하고, 버튼을 표 바로 위 우측으로 정렬. (6fcd165)
 •  *법원진행내역 컬럼 메뉴 통일 + 순서변경 토글 전환* — 자체 상태:드래그 로직을 걷어내고 useColumnResize + 컬럼 드롭다운으로 전환. 항상 드래그되던 헤더를 순서 변경 모드일 때만 드래그하도록 바꿔 나머지 표와 동작을 맞추고 너비:순서:표시여부를 localStorage에 저장. (93ea737)
