## 📝 상세 업무 내역

### 1. 홈페이지 V2 — 레거시 도메인 컷오버 대비 SEO 정비

#### 🔀 옛 URL 자동 이전 · 테스트서버 색인 차단

- **레거시 URL 301 이전** — 옛 ASP.NET 주소(`/{지역}/wincasedetail?index=N` 등)를 V2 클린 주소(`/{지역}/cases/N`)로 301 리다이렉트, 지역·ID를 보존하고 쿼리스트링은 제거. 폐기된 해외지사(vietnam·china) 경로는 홈으로 301. (`middleware.ts`, `lib/legacy-redirects.ts`) (`227833e`)
- **테스트서버 noindex 가드** — 정본 호스트(www)가 아닌 서버는 robots 전면 차단과 `X-Robots-Tag: noindex` 응답 헤더로 검색엔진 색인을 막고, www 전환 시 자동 허용되도록 처리. (`lib/host.ts`, `app/layout.tsx`, `app/robots.ts`) (`227833e`)
- **canonical 정리** — 모든 페이지가 홈으로 canonical 되던 문제를 제거해 상세글은 지역 없는 자기 주소로, 지사 페이지는 각자 자기 주소로 색인되도록 정리. (`227833e`)

#### 🗺️ sitemap 통합

- **정적 sitemap 제거·동적 통합** — 2024년 옛 주소 2,328개가 담긴 `public/sitemap.xml`(컷오버 후 전부 301 대상 → 크롤 낭비·경고 유발)과 표본용 `sitemap_busan.xml` 삭제. 동적 콘텐츠 사이트맵을 표준 이름 `/sitemap.xml`(`app/sitemap.xml/route.ts`)로 이동해 항상 현재 V2 주소(200·canonical 일치)만 출력, 중복 `/sitemap_content.xml` 라우트 제거, robots는 `/sitemap.xml` 하나만 광고. (`87c399a`)

#### 🤖 구조화 데이터(JSON-LD) 보강 — AEO/GEO 대비

- **Article 본문 보강** — 상세글 Article JSON-LD에 본문 전체(desc + 단계별 서사)를 `articleBody`로 추가해 생성형·답변 엔진이 실제 사건 내용을 읽도록 함, `dateModified` 추가(수정일 부재 시 발행일과 동일). `content-seo`에 HTML 제거 유틸(`stripHtml`)·articleBody 생성 함수 추가. (`components/seo/article-jsonld.tsx`, `lib/content-seo.ts`) (`3dfaded`)
- **센터·동영상 스키마 추가** — 전문센터 페이지에 Center JSON-LD, 법승TV 동영상 목록에 VideoObject JSON-LD 신규 추가. (`components/seo/center-jsonld.tsx`, `video-jsonld.tsx`) (`3dfaded`)

### 2. 홈페이지 V2 — 성공사례·변호사 노출 개선

- **숨김 변호사 제외·지역지사 폴백** — 게시물 변호사 뱃지 생성 시 `useflag='N'`(숨김) 변호사를 목록·상세 양쪽에서 제외(전 게시물 적용). 성공사례(type1)에서 노출 변호사가 하나도 남지 않으면 그 글의 지역지사(companyindex)를 '법무법인 법승 OO' 텍스트로 대체 표기하고, 지사 정보가 없는 글은 아무것도 표시하지 않음(지사 폴백은 성공사례 한정). (`backend/bbs.service.ts`, `bbs-card-grid.tsx`, `bbs-detail-view.tsx`) (`f86624f`)
- **대표사례 정적 그리드화** — 변호사 상세의 대표 실제사례 노출을 자동 슬라이드 캐러셀에서 정적 그리드로 전환. `cases-carousel` 제거·`cases-grid` 신규, 캐러셀용 `overflow-hidden` 등 불필요 레이아웃 정리. (`lawyers/[id]/cases-grid.tsx`) (`47e02dc`)
- **변호사 편집 폼 개선** — 직급을 자유입력에서 드롭다운(정규 목록, 미존재 기존 값은 임시 옵션으로 얹어 유실 방지)으로 변경, 전문분야·인증을 생 HTML 입력에서 '자격명 + 인증 배지' 항목별 입력으로 변경(저장 시 목록 HTML 자동 생성), 사이트 미노출 언어 필드를 편집 폼·백엔드(DTO·수정·생성·조회)에서 제거. (`admin/lawyer/lawyer-editor.tsx`, `backend/admin-lawyers.service.ts`) (`934e534`)

### 3. 홈페이지 V2 — 상담 접수 성능·유입 추적

- **응답 속도 개선** — reCAPTCHA 검증(구글 왕복)과 상담 카테고리 조회(DB)를 `Promise.all`로 병렬 처리해 대기시간을 겹치고, CRM 요청함 전달을 await하지 않는 fire-and-forget으로 전환해 유저가 CRM 콜드스타트(최대 4초)를 기다리지 않고 DB 저장 직후 즉시 응답. 접수는 DB 저장이 source of truth라 CRM 전달이 늦거나 실패해도 유실 없음, reCAPTCHA 실패 시엔 병렬 그룹이 reject되어 봇 차단 동작은 유지. (`backend/consult.service.ts`) (`e6885da`)
- **유입경로·접속 IP 기록** — 미들웨어가 첫 방문 시 외부 Referer를 `lw_funnel` 쿠키로 24h 고정(first-touch, 내부 이동은 direct), 상담 제출 시 유입 쿠키와 폼 위젯 라벨을 결합해 funnel로 전송. 접속 IP는 클라이언트 값을 믿지 않고 서버 `@Ip()`로 확정(IPv6-mapped IPv4 제거 후 regip 저장), 리다이렉트 응답에도 유입 쿠키를 실어 유실 방지. (`middleware.ts`, `backend/consult.controller.ts`·`service.ts`) (`c6dea21`)

### 4. 홈페이지 V2 — 어드민·UI 정리

- **단축 URL 관리 화면 제거** — 어드민 사이드바 '단축Url 관리' 메뉴·페이지·매니저·서버액션과 백엔드 CRUD 컨트롤러·서비스·모듈 등록 삭제(약 804줄 제거). 명함·QR·광고에 배포된 링크 보호를 위해 `/change/urls` 리다이렉트와 공개 short-urls 모듈은 유지 — 새 발급은 중단, 기존 링크 리다이렉트만 동작. (`fd31506`)
- **플로팅 버튼 확대** — 우측 하단 카톡·톡톡·예약·맨위로 버튼 크기(모바일 h-14.5·데스크톱 h-16.75)와 아이콘 확대, 라벨 폰트 10px→14px로 키워 가독성 개선. (`layout/floating-actions.tsx`) (`d5b7bdc`)
- **헤더 확대** — GNB 영문 라벨 15px→20px·국문 13px→17px, 메가패널 상세 메뉴 라벨·설명 확대, 데스크탑 헤더 높이 80px→96px 상향. (`site-header.tsx`, `site-nav.tsx`) (`7f237de`)
