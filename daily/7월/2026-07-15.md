# 일일 업무 보고 (2026. 07. 15)

> 수발신 문서 **결재 워크플로를 이메일 안에서 끝까지 처리 가능한 형태로 완성**했다 — Gmail에서 페이지 이동 없이 승인하는 AMP 인이메일 결재(이슈 #15), 승인 시 Drive 원본에 "[결재완료]" 댓글 자동 첨부, 문서 상세 딥링크 + 로그인 후 원경로 복귀까지 붙였다. 병행해 프론트+백을 **단일 Cloud Run 서비스(lawwin-case)로 통합 배포**(모든 API를 `/api` 밑으로, SPA 폴백 서빙)하고, 목록 표 4종을 **공통 DataTable**(컬럼 폭·순서·표시 저장)로 일원화했다. 미수금 목록에 당사자·사건명과 계약 사이드 패널, gzip 응답 압축, 알림 시각 UTC 오차 수정·상주형 토스트도 더했다. CRM은 상담 일정에 **구글 드라이브 파일 첨부** 기능을 신설하고 드라이브 로고 표시를 실제 SVG 도형으로 정교화, 전화번호를 하이픈 형식으로 통일했다 — 금일 커밋 21건(2개 repo)

## 📝 상세 업무 내역

### 1. 사건관리 앱 — 결재(document-logs) 워크플로 완성

> 배경: 수발신 문서 결재가 메일→앱 이동·확인 클릭 등 단계가 많고 원본 파일에 결재 흔적이 남지 않았음. 이메일 안에서 바로 승인하고, 승인 사실을 Drive 원본에 남기며, 메일 링크가 항상 문서 전체 맥락(상세 드로어)으로 연결되도록 결재 동선을 정리.

- **AMP 인이메일 결재 + 결재자·기안자 표시 (이슈 #15)** — 결재 요청 메일에 AMP4EMAIL 파트를 실어 Gmail 등에서 페이지 이동 없이 [승인] 가능하게 하고, 미지원 클라이언트는 `text/html` 폴백 렌더. 고정 발신계정·AMP action-xhr 대상을 위한 `APPROVAL_SENDER_EMAIL`·`BACKEND_PUBLIC_URL` 설정을 추가하고, `_build_approval_amp_body` + `send_approval_email` amp 파트를 구현. 스키마·API에 `approver_name`·`created_by_name`을 노출해 목록·알림에 결재자/기안자를 표시하고, 문서 삭제 시 notifications 쿼리를 무효화. (`document_logs_api.py`, `core/gmail.py`, `core/google_drive.py`, `document_logs_schema.py`, `NotificationCenter.tsx`, `useDocumentLogs.ts`) (`38850b3`)
- **결재 승인 시 Drive 파일에 "[결재완료]" 댓글 자동 첨부** — 결재를 승인하면 해당 Drive 파일(PDF·Docs·이미지·MS Office 등)에 `comments.create`로 "[결재완료]" 댓글을 남김. 인앱 결재는 로그인 사용자, 이메일 토큰 결재는 결재자(`approver_key`) 이메일로 DWD 위임한다. best-effort — 파일 없음·권한 없음·실패해도 결재 처리에는 영향 없음. (`document_logs_api.py`, `core/google_drive.py`) (`f30d0c1`)
- **결재 이메일 문서 상세 딥링크 + 로그인 후 원경로 복귀** — 결재 요청 이메일에 "앱에서 문서 상세 보기" 딥링크(`/document-logs?doc=<id>`)를 추가하고, 로그인이 필요한 딥링크로 진입해도 OAuth 라운드트립 후 원래 URL로 복귀하도록 sessionStorage 기반 복귀 경로(`authRedirect`)를 도입. 목록 화면은 `?doc` 쿼리와 전역 상세 드로어를 양방향 동기화. (`gmail.py`, `client.ts`, `AuthCallbackPage.tsx`, `DocumentLogListPage.tsx`, `authRedirect.ts`, `ProtectedRoute.tsx`) (`075feb7`)
- **"코멘트 후 결재"를 상세 패널로 연결 + 버튼 승인/반려 통일** — "코멘트 후 결재" 링크를 별도 결재 페이지 대신 목록 화면의 상세 드로어(`/document-logs?doc=<id>`)로 연결해 로그인 후 문서 전체 맥락을 보고 코멘트와 함께 결재하도록 변경. 중복되던 "앱에서 문서 상세 보기" 링크는 제거하고, 이메일·상세 패널·결재 페이지의 버튼 라벨을 "승인/반려"로 통일. (`document_logs_api.py`, `gmail.py`, `ApprovalPage.tsx`, `DocumentLogDetailDrawer.tsx`) (`987950a`)

### 2. 사건관리 앱 — 프론트+백 통합 배포(Cloud Run)

> 배경: 프론트와 백엔드를 각각 배포하던 구성을 단일 서비스로 합쳐 오리진 분리·CORS·URL 관리 부담을 없앰.

- **프론트엔드 Cloud Run 배포 구성 추가** — frontend 멀티스테이지 Dockerfile(node→nginx) + nginx SPA 설정, `.env.production`에 프로덕션 백엔드 URL(`VITE_API_BASE_URL`), `.dockerignore`/`.gcloudignore`를 추가. Cloud Build(리눅스)에서 한글 파일명 인코딩이 깨져 빌드가 실패하던 문제를 로고 파일명 한글→ASCII(`lawwin-logo.png`)로 해결하고 미사용 로고 2개 제거. `lawwin-case` 서비스로 `flutter-crm-e44f5 / asia-northeast3`에 배포. (`frontend/Dockerfile`, `nginx.conf`, `Sidebar.tsx`, `LoginPage.tsx`) (`dfbd26c`)
- **프론트+백 단일 Cloud Run 서비스(lawwin-case) 통합** — Vite 빌드→FastAPI 정적 서빙까지 단일 이미지로 통합(`Dockerfile`). 프론트 화면경로(`/cases`·`/document-logs` 등)와 충돌하지 않도록 모든 API 라우터를 `/api` 프리픽스로 이동하고, dist를 `backend/app/static`으로 복사해 `/assets` 마운트 + 그 외 GET 경로를 `index.html`로 SPA 폴백. 시크릿을 `backend/.env`로 마운트하면 소스 볼륨을 가리는 문제를 `APP_ENV_FILE` 환경변수로 경로를 분리해 회피. AMP 결재 액션 URL도 `/api` 프리픽스로 정정, `python-multipart` 추가. (`main.py`, `core/config.py`, `document_logs_api.py`, `requirements.txt`, `.env.production`, `.gcloudignore`) (`2d0960a`)

(`components/common/data-table/*`, `ConsultationFeesPage.tsx`, `ContractListPage.tsx`, `ReceivableListPage.tsx`, `RecordRequestListPage.tsx`) (`e89665a`)

### 4. 사건관리 앱 — 미수금·성능·알림·UX

- **미수금 목록 당사자명·사건명 표시 + 계약 사이드 패널** — 계약→수임(matter)→당사자 batch 조인으로 `party_name`·`matter_title`을 API 레이어에서 enrich(`matters.party_key` 우선, `cases.party_key` 폴백). 목록의 "계약 #id" 링크를 URL 이동 없이 이 화면에서 `ContractSidePanel`로 바로 열도록 변경. (`receivables_api.py`, `receivables_schema.py`, `receivables.ts`, `ReceivableListPage.tsx`) (`ec0a7b1`)
- **큰 JSON 응답 gzip 압축 미들웨어** — 사건 목록(limit=1000, ~1.1MB) 등 큰 JSON 응답을 gzip 압축해 전송량을 대폭 줄임(`minimum_size=1000` 미만은 비압축). (`main.py`) (`15cf948`)
- **알림 시각 UTC 오차 수정** — 백엔드가 `created_at`을 타임존 없는 naive UTC로 반환하는데 JS가 로컬(KST)로 오해해 +9시간 어긋나던 문제를, 타임존 표기가 없을 때만 명시적으로 UTC로 해석(이중보정 방지)해 수정. (`NotificationCenter.tsx`) (`107a4df`)
- **미읽음 알림 토스트 우하단 상주형(카카오톡 스타일)** — position bottom-right + duration Infinity로 클릭/X 전까지 유지(일시 피드백과 분리), id 부여로 같은 알림 재토스트 방지, closeButton 추가(팝업만 닫히고 벨엔 잔존). 결재 외 알림도 `ref_id`가 있으면 '열기' 액션 노출. (`NotificationCenter.tsx`) (`389f12d`)
- **검색 드롭다운 방향키 이동·Enter 선택** — 수발신 사건/방법/담당자 검색, 당사자 검색, 공용 추천 입력에서 ↑/↓ 이동·Enter 선택·Esc 닫기를 지원하고 마우스 hover와 동기화, 하이라이트 항목 자동 스크롤. (`pickers.tsx`, `PartyAddCard.tsx`, `SuggestionInput.tsx`) (`a759d1f`)
- **Google Picker 한글 로케일 / 타입 빌드 정리** — Picker 3종(계약서·문서·폴더 선택)에 `setLocale("ko")` 적용(`31bb2dc`). 판별 유니온 Omit을 `DistributiveOmit`으로 교체, `z.coerce`로 input≠output이라 어긋나던 zodResolver를 `Resolver<CaseFormValues>`로 캐스팅하는 등 빌드 타입 정리(`CaseFormPage`·`CaseDetailPage`·`PartyAddCard` 등). (`7233cd0`)

### 5. CRM — 상담 드라이브 첨부·표기 통일

- **상담 일정에 구글 드라이브 파일 첨부 기능 추가** — 상담 폼에서 구글 Picker로 내 드라이브·공유 드라이브 파일을 골라 캘린더 일정에 첨부(한글 UI). Picker용 액세스 토큰 발급 API를 추가(저장된 `refresh_token` 재사용, 추가 동의 불필요)하고, 캘린더 이벤트 생성·수정 시 `attachments`로 전달하며 `supportsAttachments` 활성화. 첨부 메타는 `party_consultation.calendar_attachments`(JSONB) 컬럼에 저장(마이그레이션 포함). 파일 자동 공유는 하지 않으며 열람 권한은 기존 드라이브 공유 설정을 따름. (`authController.js`, `partyConsultationController.js`, `googleCalendarService.js`, `google_picker/*`, `consultation_form_screen.dart`, 마이그레이션) (`d6b9b12`)
- **Picker 토큰 발급 실패 시 서버 원인 메시지 노출** — 백엔드가 `error/code`로 주는 응답을 프론트가 `message`만 읽어 원인이 가려지던 문제 수정. `GOOGLE_REAUTH_REQUIRED` 코드면 재로그인 안내를, 그 외 실패는 서버 error 메시지와 HTTP 상태코드를 함께 노출. (`consultation_form_service.dart`) (`f280c87`)
- **첨부파일 드라이브 로고 표시 정교화(4단계)** — 첨부 아이콘을 클립→드라이브 아이콘으로 교체(`df762da`)한 뒤, 폰트 아이콘 미렌더 문제를 CustomPaint 직접 렌더로 대체(`9e85afd`), 실제 드라이브 로고 SVG 좌표(87.3×78) 3개 면으로 정교화(`b00062c`), 최종적으로 모서리 둥근 삼각형 클립 방식으로 도형을 안정화(`2d7bbf9`). (`consultation_form_screen.dart`)
- **연락처 하이픈 형식 통일 표시** — 공용 전화번호 포맷터(`phone_formatter.dart`)를 추가해 숫자만 저장된 값도 하이픈 형태로 표시. 당사자 목록·상세, 상담관리 목록, 문자 내역 목록에 적용하고 국제번호 등 알 수 없는 형식은 원본 유지. (`party_screen.dart`, `party_detail_screen.dart`, `consultation_screen.dart`, `sms_history_screen.dart`) (`842a254`)

**금일 종합:** 오늘의 중심은 **수발신 문서 결재를 이메일 안에서 완결**시킨 것이다 — Gmail에서 페이지 이동 없이 승인하는 AMP 인이메일 결재(이슈 #15)에 더해, 승인 시 Drive 원본에 "[결재완료]" 댓글을 남기고, 메일 링크가 항상 문서 상세 드로어로 연결되며 로그인 후 원경로로 복귀하도록 결재 동선을 정리했다. 인프라 쪽으로는 프론트와 백엔드를 **단일 Cloud Run 서비스(lawwin-case)로 통합**(API를 `/api` 밑으로, FastAPI가 SPA 폴백 서빙)해 배포·오리진 관리를 단순화했다. 병행해 목록 표 4종을 공통 DataTable로 일원화하고, 미수금 이름 표시·계약 사이드 패널, gzip 응답 압축, 알림 UTC 오차·상주형 토스트로 조회 화면과 알림 UX를 다듬었다. CRM은 상담 일정에 구글 드라이브 파일 첨부를 신설하고 드라이브 로고 표시를 실제 SVG 도형으로 정교화, 전화번호를 하이픈 형식으로 통일했다. 금일 2개 repo에 걸쳐 커밋 21건.
