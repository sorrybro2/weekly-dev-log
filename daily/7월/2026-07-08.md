## 📝 상세 업무 내역

### 1. 홈페이지 V2 — 세로 모니터(포트레이트) 반응형 대응

> 배경: 모니터를 세로로 세워 쓰는 사용자 화면(폭 1024~1280px)에서 상담 접수바·헤더·변호사 상세 등이 깨진다는 확인. 원인은 데스크탑 가로 레이아웃의 분기점이 `lg`(1024px)여서, 실제로는 ~1280px 이상이 필요한 레이아웃이 세로 모니터 폭에서 넘치는 것. 분기점을 `xl`(1280px)로 올려 그 구간은 좁은 화면 레이아웃으로 안전하게 흐르도록 정리.

- **상담 접수바 전 페이지 노출 + 좁은 화면 dock 전환** — 메인 페이지에만 렌더되던 하단 상담 접수바를 공통 레이아웃으로 올려 전 페이지에 노출하고, 자체 상담 폼이 있는 전문센터와 별도 레이아웃인 어드민에서는 컴포넌트 자체 판별로 제외. 아울러 데스크탑 가로 폼과 우측 플로팅 채널 버튼의 분기점을 `lg`→`xl`로 올려 세로 모니터에서는 4칸 dock만 뜨도록 해 폼이 넘쳐 깨지던 문제와 dock·플로팅 중복 노출을 함께 제거. (`app/(site)/layout.tsx`, `app/(site)/page.tsx`, `components/layout/bottom-contact-bar.tsx`, `floating-actions.tsx`) (`15bc818`)
- **헤더·푸터·상세 화면 반응형 정리** — 헤더의 전화 상담 버튼은 좁은 화면에서 문구를 숨기고 아이콘만 노출해 줄바꿈·넘침 방지, 푸터 지사 목록은 5열→4열, 변호사 상세의 사진·본문 2단 구성은 `xl` 이상에서만 적용하고 그 미만은 세로로 쌓음, 회사소개 경영이념 카드는 좁은 화면에서 4열→2열로 조정. (`components/layout/site-header.tsx`, `site-footer.tsx`, `app/(site)/lawyers/[id]/lawyer-stage.tsx`, `app/(site)/about/page.tsx`) (`e4d8506`)
- **관리자 목록 표 가로 스크롤** — 관리자 목록 표 11곳이 좁은 화면에서 열이 잘리던 문제를, 표 감싸개를 '넘침 숨김'에서 '가로 스크롤'로 바꿔 모든 열을 확인 가능하게 함. (`app/(admin)/**/*-list.tsx`·`*-manager.tsx` 11개) (`0a4e120`)
- **히어로 영역 높이 축소** — 전문센터·메인 히어로가 세로 모니터에서 지나치게 높아 상단 여백만 커지던 문제를, 세로 화면(`portrait`)에선 높이를 낮추고 가로 대형 화면에서만 시네마틱 높이를 유지하도록 조정(메인은 세로 중앙 정렬 추가). (`components/center/center-hero.tsx`, `components/home/hero-cinematic.tsx`) (`c9afca9`)

### 2. 홈페이지 V2 — 변호사 상세 화면 정적화

- **진입 애니메이션 제거** — 변호사 상세 진입 직후 사진이 화면을 가로질러 좌측으로 이동하고 배경이 다크→라이트로 전환되던 ~4초 자동 연출을 제거하고, 처음부터 정적 2단 화면으로 표시. 정보 탐색을 방해하고 재방문 시 피로하다는 판단. 연출 안에만 존재하던 상담 신청 버튼·전화번호는 사진 바로 아래로, 전문분야 태그는 이름 아래로 옮겨 항상 노출되게 보존. 부수적으로 세로 모니터에서 사진만 어긋나 움직이던 문제도 해소. (`app/(site)/lawyers/[id]/lawyer-stage.tsx`) (`c835da1`)

### 3. 홈페이지 V2 — 전문센터 게시물 정리

- **사례·칼럼 3개·3열로 정리** — 전문센터의 사건사례·지식칼럼 노출 개수를 4개→3개로 줄이고, 카드 그리드를 최대 3열로 맞춰 4열에서 생기던 빈칸·좁은 카드를 제거. 강점·통계 카드는 넓은 화면에서만 4열로 펼치고 세로 모니터에선 2열을 유지. 카드 그리드 컴포넌트에는 열 구성을 외부에서 지정하는 옵션을 추가해 다른 목록(사례·지식 4열)에는 영향이 없도록 함. (`components/center/center-page-body.tsx`, `components/bbs/bbs-card-grid.tsx`) (`b3e42ba`)

### 4. 홈페이지 V2 — 동영상 탭 유튜브 채널 헤더

- **채널 헤더 추가** — 동영상 탭 상단에 실제 유튜브 채널 페이지처럼 배너·원형 아바타·채널명·구독자수·영상수·구독 버튼을 표시. 채널 정보는 YouTube `channels.list`를 24시간 캐시로 1회 조회(사실상 quota 무비용)하고, API 키 미설정·실패 시 정적 값으로 대체(아바타는 로고로 폴백). 채널 아바타 이미지 도메인(`yt3.ggpht.com`·`googleusercontent`)을 허용에 추가하고, 기존 안내 문구+구독 버튼 조합을 채널 헤더로 대체. (`components/youtube/youtube-channel-header.tsx`, `features/youtube/api.ts`·`types.ts`, `components/news/news-section.tsx`, `next.config.ts`) (`93ebbc9`)

### 5. 사건관리 앱 (BS_CASE_MANAGEMENT)

- **수발신 문서 목록 반응형 페이지네이션** — 고정 12건/페이지였던 수발신 문서 목록을, 테이블 컨테이너 높이를 감지(ResizeObserver)해 채울 수 있는 행 수를 자동 계산하도록 변경(채울 수 있는 행의 80%만 노출). 계약 관리 페이지 크기는 25→20으로 조정. 구분 배지는 `whitespace-nowrap`과 열 폭 조정으로 세로 줄바꿈을 방지해 가로로 표시. (`features/documents/components/DocumentLogListPage.tsx`, `features/contracts/components/ContractListPage.tsx`) (`82e62eb`)
- **미사용 코드 정리·타입 보정** — 계약·사건 화면의 미사용 import·상수·컴포넌트를 제거하고, `matterId`를 nullable로 허용(계약 선택 모달→사건 목록), `receipt_issued` optional 필드 추가·`getEmployees` 호출 형태를 보정. (`features/contracts/*`, `features/cases/*`, `api/receivables.ts` 등 9개 파일) (`ecaec1a`)
