## 📝 상세 업무 내역

### 1. 사건관리 앱 — 상담료(상담 관리) 페이지 개편

#### 🧩 레이아웃 및 입력 UI

- **좌·우 1:1 분할** — 상담료 목록 / 처리 대기를 탭 전환에서 좌우 동시 표시로 개편, 각 영역 독립 스크롤. (`d12d74e`)
- **모달 정비** — 상담료 입력 모달의 메모 칸 확대(6줄·세로 리사이즈) 및 스크롤 정비. (`bbfa34d`)

#### 🔗 처리 대기 — CRM 방문상담 스케줄 연동

- **자동 매핑** — 처리 대기 항목 클릭 시 상담료 입력 폼에 의뢰인·상담일·유형·메모 및 **상담 변호사(`counselors_key`)** 자동 채움. (`d12d74e`, `f7a5d61`)
- **상태 필터** — 예약·접수·완료·취소·노쇼 다중 선택 필터 및 접수 상태 추가. (`f7a5d61`, `bbfa34d`)
- **검색** — 의뢰인명·사건명·상담자명 실시간 검색(부분일치). (`bbfa34d`)
- **페이지네이션** — 10건/페이지 적용, 필터·검색·사무소 변경 시 첫 페이지로 리셋. (`bbfa34d`)
- **처리 완료 정비** — 노쇼·취소는 상담료 입력 대신 처리 완료만 노출, tombstone 레코드를 실제 사무소·유형으로 생성. (`f7a5d61`, `bbfa34d`)

#### 🏢 모든 지사 조회

- 사무소 선택에 **'모든 지사'**(정보실 제외 전 지사 합산) 옵션 추가. (`bbfa34d`)
- 본인 소속(`organization_key`)이 제외 대상(정보실)일 때 기본 선택이 정보실로 잡혀 데이터가 노출되던 문제를, 기본값을 '모든 지사'로 전환하여 해결. (`bbfa34d`)

#### 📄 계약 화면 의뢰인명 조회 보정

- 계약 목록/상세의 **의뢰인명 조회 경로 수정 및 라벨메모 표시**(`7fefa86`), 레거시 데이터에 대한 **폴백 로직 추가**로 이름 누락 방지. (`aea5dc7`)

#### ⚡ 성능 최적화 및 백엔드 (`backend/app/api/consultation_fees_api.py`, `crud/consultation_fees_crud.py`)

- **처리 대기 조회 8초 → 0.05초** — `crm.*`가 외부 CRM DB의 postgres_fdw foreign table임을 확인. 원격에 푸시다운되지 않는 인라인 JOIN을 제거하고, 스케줄 선조회 후 이름을 배치 조회하는 방식으로 전환(약 160배 개선). (`d12d74e`, `bbfa34d`)
- **다중 사무소 지원** — pending-queue·목록 API가 쉼표 구분 다중 사무소 조회를 지원하도록 확장. (`bbfa34d`)

#### 🛠️ 로컬 개발 환경 구축

- GCP Secret Manager에서 `.env`·서비스계정 키 복원, Python venv 생성 및 백엔드 의존성 설치, Cloud SQL Auth Proxy + FastAPI(uvicorn) 기동 및 DB 연결 검증(테이블 221개).
