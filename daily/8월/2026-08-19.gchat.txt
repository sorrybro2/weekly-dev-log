🗂 *〔사건관리 앱 모바일 오버레이 정리〕*

•  *다이얼로그 기본 높이 부재* — DialogContent 에 높이 제한과 스크롤이 없어 내용이 길면 위아래가 동시에 잘리고 페이지 스크롤도 안 먹었음. 모바일에서 기일 상세 저장 버튼에 아예 도달할 수 없던 원인 (b26bb6a)
•  *vh 를 dvh 로 전환* — 실기기 모바일은 주소창이 뷰포트를 먹어 90vh 가 실제 표시 영역보다 큼. 데스크톱 반응형 모드에선 재현되지 않던 종류. 12파일 (194721d)
•  *개별 모달 상수 보정* — min-h 가 CSS 우선순위상 max-h 를 이겨서 화면이 짧으면 그대로 잘리던 것 등 5파일 (904a5dc)
•  *드롭다운 좌표 공통화* — 포털 드롭다운 12곳이 전부 트리거 밑에 붙이기만 해서 폼이 긴 화면 아래쪽에선 목록이 화면 밖에 그려져 선택 자체가 불가능. dropdownCoords 로 모아 아래가 모자라면 위로 뒤집게 함 (c2c71be)
•  *팝오버 상수 높이 제거* — 참석자 팝업이 높이를 상수로 못 박아 실제 높이가 커지면 저장 줄이 화면 밖으로, 브라우저가 상수보다 작으면 값이 음수가 되어 위로 밀려났음. ResizeObserver 로 실측 (054896a)
•  *문서등록 필터 접기* — 폰에서 필터가 3줄을 먹어 목록이 5건만 보였음. 접힌 상태에서도 무슨 조건인지 한 줄 요약으로 보여줌 (5569cc7)
•  *배포 위험 2건 등록* — 시크릿을 latest 로 참조해 배포 실패하는 문제, 동시 배포로 옛 커밋이 최신 배포를 덮어쓴 문제가 금일 두 번 발생 (이슈 360번, 361번)

👤 *〔CRM 구글 어드민 연동과 문자 발신 지역〕*

•  *개명 미반영 수정* — 어드민에서 이름을 바꿔도 DB 가 그대로였음. 변경 감지 로직이 실제 UPDATE 문과 어긋나 이름만 바뀌면 변경 없음으로 걸러져 UPDATE 가 스킵됐음 (7d1b60a)
•  *운영 데이터로 재현* — 디렉터리 108명 대조로 불일치 1건 확인. 그 실제 행으로 수정 전은 스킵, 수정 후는 반영을 확인
•  *데이터 손상 동시 차단* — 기존 SQL 이라 UPDATE 가 실행되는 순간 근무형태가 전속에서 정규로, 입사일이 계정생성일로 덮여 썼음. 이름만 고치면 오히려 손상이 늘어나는 구조였음
•  *배포 후 검증* — 새 리비전 폴링이 27건에서 28건으로 1건 더 갱신. 배포 전 스캔의 불일치 1건과 일치 (이슈 2번)
•  *문자 발신 지역 초기값* — 로그인 직원 지사 고정에서 당사자의 지역지사로 변경. 당사자 드롭다운이 지사 정보를 아예 내려주지 않던 것부터 추가 (66dc063)
•  *운영 커버리지 98.1퍼센트* — 40,972건 중 40,210건 자동 지정. 폴백 762건 중 694건은 제주지사로 발신번호가 설정돼 있지 않음 (이슈 3번)
•  *403 회피 설계* — 허용된 발신번호 목록 안에서만 매칭해 스코프 밖 값이 초기값으로 들어가 발송 시점에 막히는 일이 구조적으로 없게 함
