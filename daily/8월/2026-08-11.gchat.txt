🚀 *〔도메인 롤백과 V2 이전〕* (이슈 104)

•  *www 를 레거시로 롤백* — SEO 노출과 AI 인용이 끊겼다는 대행사 보고 및 경영 판단: 가비아 A 레코드를 ALB 에서 레거시 IIS 로 되돌림
•  *레거시 서버 실측 후 전환* — HTTPS 200, 응답 0.12에서 0.17초, 인증서 2027년 3월까지 유효, robots 전면 허용 확인
•  *V2 는 bslawwin.co.kr 로 이전* — 인증서 신규 발급 및 인증서 맵 항목 추가, A 레코드 2개. URL map 은 손대지 않았음(기본 서비스가 이미 전 호스트를 받음)
•  *CORS 를 안 고치면 상담 접수가 죽음* — 새 도메인을 백엔드 허용 목록에 추가. 응답 헤더 누락을 실측으로 먼저 확인
•  *인프라는 전부 유지* — Cloud Run, ALB, 인증서 관리자, GCS 를 새 도메인이 그대로 재사용

🔍 *〔SEO 도메인 일원화와 재등록〕*

•  *도메인이 16개 파일에 하드코딩* — 새 도메인에서 robots 가 전면 차단, 표준 주소가 이전 도메인, 응답 헤더가 noindex 상태였음 (17f28ba)
•  *표준 주소가 결정적* — robots 를 열어도 표준 주소가 다른 도메인을 가리키면 색인이 되지 않음
•  *설정값 한 곳으로 통합* — 다음에 도메인이 바뀌면 배포 설정 한 줄만 고치면 됨. 정적 생성 페이지가 값을 빌드 시점에 굳혀 빌드 인자로도 주입
•  *네이버 소유확인 토큰은 도메인마다 다름* — 새 토큰 추가, 이전 토큰도 되돌릴 때를 위해 함께 유지 (f43efcc)
•  *사이트맵 실측* — 7,298 URL, 630KB, 도메인 불일치 0, 중복 0. 네이버 제한 대비 여유
