## 법무법인 홈페이지 V2 리뉴얼 — 1인 풀스택

**기간** 2026.05 – 진행 중

**핵심 업무**
- **Next.js 렌더링·인터랙션**: 서버 헤더에서 전화 버튼의 클라이언트 동작을 분리. JS 실행 전 숨겨지던 콘텐츠의 등장 연출을 CSS로 옮겨 첫 화면 표시와 동작 줄이기 설정 대응
- **이미지·화면 구성**: 현재 히어로 이미지에 우선 로딩을 적용하고 대표 원본을 WebP로 변환해 **5.54MB → 589KB**로 축소. 전문센터 공통 레이아웃 구현
- **반응형 어드민 UI**: 기존 기준이 없던 어드민 목록 12개에 **md(768px) 미만 카드·이상 표** 전환 기준을 직접 수립해 순차 적용. 터치 영역 22px·16px → 36px·44px 확대, 태블릿 구간 저장 바 여백 불일치 수정
- 레거시 SQL Server → PostgreSQL **730만 건** 데이터 이관
- 상담 접수 API `Promise.all` 병렬 처리 + fire-and-forget으로 콜드스타트 대기 **4초 제거**
- SEO/AEO: 레거시 주소 301 이전, 2024년 옛 주소 **2,328건** 정적 sitemap 제거·동적 통합, LegalService JSON-LD sameAs 주입 및 저자 Person 귀속으로 AI 답변엔진 엔티티 혼동 대응
- 보안: 상담 PII 마스킹, 전역 보안 헤더, reCAPTCHA v3 fail-closed 전환, 어드민 Google 로그인 일원화
- CMS: 예약 발행, 이미지 드래그 업로드, 자동 TOC, PDF 첨부, CSV 다운로드(마스킹)
- Cloud Build 업로드 용량 **7.6GB → 115MB**, Kaniko→BuildKit 빌드 단축, ALB+Certificate Manager로 무중단 도메인 컷오버

- **사례 3,038건 AI 요약·FAQ**: 생성 → 원문 대조 자동 검사(지어낸 숫자·비율·보장 표현 차단) → 자동 공개 파이프라인 구축. 변호사 광고 규정 해석에 맞춰 "AI 표기 없이 실제로 검토한 변호사만 표시"로 설계 변경
- 바뀐 글을 IndexNow(빙·네이버)와 사이트맵 수정일(구글)로 통지하는 변경 감지 모듈, 첫 통지 7,227건
- "조용한 실패" 3건 해결: 종료코드 0으로 2주간 성공 보고되던 동기화(26시간 침묵 감시 추가), 번호 충돌로 사라질 뻔한 상담 305건 복구, 운영에서 한 번도 동작하지 않던 구글 권한 연동(직원 109명) 수정

- 레거시→신규 홈페이지 동기화: "포트 차단" 오진을 재측정으로 바로잡고 HTTPS 밀어 넣기 구조로 전환해 방화벽 의존 제거, 게시물 61건·상담 305건·예약 글 38건 복구
- 레거시 업로드 원본 의존 정리: 이미지 서빙을 가비아 프록시에서 GCS로 전환, 누락 파일은 원본 서버 폴백 + 본문 사진 97장 복구
- 외주 ASP.NET 소스 사내 저장소 이관·3계층 구조 문서화, 외부 SEO 업로드 API(`X-API-KEY`) 구현, 지점 10곳 사이트맵 갱신 자동화
