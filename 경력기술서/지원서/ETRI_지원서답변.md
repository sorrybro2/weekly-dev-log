### ❌ 반드시 수정해야 하는 항목

`경력기술서_TMI.md`의 KOGAS 항목에 본인이 직접 남긴 문장:

> **분석한 배포 구조**: Docker 멀티스테이지 빌드로 생성한 Go 바이너리를 Linux systemd 서비스로 운영.
> 아래 항목은 **기존 시스템을 읽고 파악한 내용이며 본인의 신규 구현 범위와 구분합니다.**

`경력기술서.md`의 해당 항목 제목도 **"KOGAS — 신규 개발을 위한 기존 시스템 코드 분석"**이다.
Gorilla WebSocket 허브도 Docker/systemd도 **읽고 분석한 기존 코드**이지 본인 구현물이 아니다.

**위험도가 특히 높은 이유**: 지원처가 ETRI이고, 리얼타임테크는 ETRI 과제 수행사다.
2번 문항에서 본인이 "ETRI CCTV 시스템 유지보수 경험"을 직접 언급했으므로 레퍼런스 체크가 실제로 가능하다.
여기서 "구현"이 "분석"으로 드러나면 검증된 다른 성과(160배, 730만 건)까지 함께 의심받는다.

# 제출 형식 주의 — 특수문자

공고 원문: **"자기소개서 작성 시 특수문자나 특수기호 등을 입력할 경우 에러 발생의 요인이 될 수 있음"**

작성해 둔 답변을 스캔한 결과다. ASCII 문자(`[`, `]`, `&`)는 대체로 안전하나, **비ASCII 기호는 치환할 것.**

| 문항 | 검출된 기호 | 조치 |
| --- | --- | --- |
| 1번 수정안 | `·` x2 | 공백 또는 쉼표로 |
| 2번 원안 | `·` x2 | 공백 또는 쉼표로 |
| 3번 원안 | `→` x1 | `에서`로 풀어쓰기 |
| 3번 수정안 | `→` x2 | `에서`로 풀어쓰기 |
| 4번 수정안 A/B | 없음 | 안전 |
| 5번 원안 | `•` x3 | 줄바꿈 또는 `-` |
| 5번 수정안 | `•` x3, `·` x3 | 위와 동일 |

**치환 규칙**

- `→` 는 `8초에서 0.05초로`, `1695ms에서 109ms로` 처럼 풀어쓴다
- `·` 는 공백 또는 쉼표로 (`학과-학생`의 하이픈은 ASCII라 안전)
- `•` 는 줄바꿈으로 항목을 구분하거나 ASCII 하이픈 `-` 로
- `[`, `]`, `&`, `%`, `(`, `)` 는 유지 가능

입력 후 **저장을 한 번 눌러 에러 여부를 확인**할 것. 에러가 나지 않으면 그대로 두어도 된다.
