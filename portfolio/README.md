# 포트폴리오 + 경력기술서

앞 3쪽은 React·Next.js 경험 이력과 경력·성과, 서비스 화면, 프론트엔드·풀스택 기술 사례로 구성합니다.
전체본은 4쪽부터 `경력기술서_TMI.md`의 프로젝트별 상세 내용을 불러옵니다.
TMI의 자기소개·전체 개관은 요약과 겹치므로 전체본의 상세 부분에서 제외합니다.
경력기술서 원문·단독 PDF에는 회사 실무만 담습니다. 전체본 말미에는 `portfolio/personal-projects.md`를 별도 개인 포트폴리오 페이지로 붙여, 프로젝트·학습의 날짜·본인 기여·GitHub 근거를 보여줍니다.

확인할 결과물은 `진솔_포트폴리오_요약.pdf`(3쪽)와 `진솔_포트폴리오_경력기술서.pdf`(요약+상세)입니다.

## 편집할 파일

- `portfolio/content.json`: 이름, 소개, 경력, 기술, 대표 성과, 프로젝트, 링크와 사진 경로
- `content.json`의 `timeline`: 개인 개발·학습·팀 프로젝트·회사 개발의 기간과 근거 링크. 최초 기록부터의 경과 기간을 실무 경력으로 합산하지 않습니다.
- `경력기술서_TMI.md`: 상세 경력의 원문
- `portfolio/personal-projects.md`: 개인 개발·팀 프로젝트·학습 이력. 포트폴리오 전체본에만 포함
- `scripts/portfolio-print.css`: 포트폴리오 3쪽의 A4 레이아웃

## 사진 넣기

아래 이름으로 파일을 넣고 다시 출력하면 반영됩니다. PNG 대신 JPG/WebP를 쓰거나 파일명을 바꾸려면 `content.json`의 `images` 경로를 수정합니다.

| 사진 | 기본 위치 | 권장 구성 |
|---|---|---|
| 프로필 사진(선택) | `assets/portfolio/profile.jpg` | 세로 4:5 정도. 첫 페이지 우측에 약 25×32mm로 표시 |
| 홈페이지 V2 | `assets/portfolio/homepage.png` | 승소사례 상세의 담당 변호사·상담 동선이 보이는 대표 구간 |
| CRM | `assets/portfolio/crm.png` | 당사자 목록과 상담 등록 기능을 보여주는 구간 |
| 사건관리 | `assets/portfolio/case-management.png` | 가장 넓게 표시. 상담료 처리 대기와 등록 목록, 상태·지사 필터가 보이는 구간 |

프로필 사진이 없으면 사진 영역을 숨깁니다. 서비스 캡처가 없으면 화면명만 표시하는 자리로 남깁니다.
캡처가 들어가기 전의 PDF는 화면 구성을 확인하는 초안입니다.
실제 화면 대신 가상의 UI 이미지를 만들지 않습니다.

서비스 캡처는 작은 글씨가 읽히도록 전체 페이지를 길게 찍기보다 담당 기능 주변을 잘라 사용합니다.
사건관리는 좌우 업무 동선이 보이는 넓은 구간, 홈페이지와 CRM은 약 16:10 비율을 권합니다.
이미지는 비율을 유지하고 전체가 보이도록 들어가며, 캡션이 담당 기능을 설명합니다.
사내 화면은 이름·연락처·사건 내용이 없는 테스트 데이터 화면이나 식별정보를 가린 캡처를 사용합니다.
인물 사진은 선택 사항이며, `images.portrait`를 `null`로 두면 숨길 수 있습니다.
`contactEmail`에 이메일을 입력하면 첫 페이지에 연락처 링크가 추가됩니다.

## 출력

기존 TMI 렌더러와 동일하게 marked 12.0.2, Playwright를 사용합니다.
모듈 준비 방법과 환경변수는 `scripts/README.md`를 참고합니다.

```text
node scripts/render-portfolio.cjs
```

다음 4개 파일이 생성됩니다.

- `진솔_포트폴리오_요약.html`
- `진솔_포트폴리오_요약.pdf` — 앞 3쪽
- `진솔_포트폴리오_경력기술서.html`
- `진솔_포트폴리오_경력기술서.pdf` — 같은 3쪽 + 상세 경력

사진은 HTML/PDF 안에 내장하므로 결과 파일만 공유해도 표시됩니다.
전체본 앞부분의 상세 링크는 같은 문서의 해당 프로젝트로 이동합니다.
요약본의 상세 링크와 전체본의 근거 링크는 GitHub의 기존 TMI 원문·업무 보고로 연결합니다.

`PDFJS_MODULE`을 지정하면 실제 PDF가 3쪽인지, 상세가 4쪽에서 시작하는지,
문서 내부 이동 링크가 유지되는지를 검사하고 임시 폴더에 전체 페이지 미리보기를 저장합니다.
사진 추가 후에는 재출력 결과를 확인해 캡처 내용과 캡션이 일치하는지 검토합니다.
