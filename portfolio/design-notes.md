# 포트폴리오·경력기술서 디자인 가이드

연한 배경 상자에 비슷한 크기의 글자가 반복되던 구성을 바꾸고, 제목·성과·설명·근거의 중요도가 먼저 보이도록 정리했습니다. 내용과 근거는 유지하며 회사 경력과 개인 포트폴리오의 구분도 유지합니다.

## 참고한 공식 자료

- [Linear — Behind the latest design refresh](https://linear.app/now/behind-the-latest-design-refresh): 정보 위계를 명확히 하고, 장식보다 내용을 중심에 두는 방향을 참고했습니다.
- [Vercel Geist — Typography](https://vercel.com/geist/typography): 제목·라벨·본문의 역할을 나누고, 본문에는 읽기 편한 행간을 두는 원칙을 참고했습니다.
- [Vercel — Design Guidelines](https://vercel.com/design/guidelines): 요소 정렬, 숫자 정렬, 문장 끝의 짧은 줄을 피하는 타이포그래피 지침을 참고했습니다.
- [Pretendard](https://github.com/orioncactus/pretendard): 한글·영문이 섞이는 기술 문서의 공통 서체로 사용합니다. 버전과 라이선스는 [폰트 안내](../assets/fonts/README.md)에 기록했습니다.

위 자료의 원칙을 인쇄 문서에 맞게 해석한 디자인이며, 특정 서비스의 화면을 복제한 템플릿은 아닙니다.

## 적용 기준

| 요소 | 기준 | 목적 |
|---|---|---|
| 본문 | Pretendard 10.5pt, 행간 1.6, `#15171B` | 한글 기술 설명을 선명하게 표시 |
| 보조 설명 | `#434A57` / `#525866` | 중요도는 낮추되 흐리게 만들지 않음 |
| 포인트 | `#2455E8` | 링크·섹션 번호·일부 성과에 일관되게 사용 |
| 제목·숫자 | 굵은 제목, 큰 성과 수치, 열 정렬 | 빠르게 훑을 때 핵심을 찾도록 구성 |
| 영역 구분 | 흰 바탕과 가는 구분선, 일정한 정렬 | 배경 상자와 장식의 반복을 줄임 |
| 아키텍처 | 기존 SVG의 크기 유지, 글자·선·테두리 대비 강화 | 확대 없이 흐름을 읽을 수 있도록 유지 |
| 화면 캡처 | 화면 번호·접근 상태·담당 기능 캡션 | 사내 서비스도 구현 범위를 설명 |

앞 3쪽은 프로필·대표 화면·기술 사례 순서입니다. 통합본의 회사 상세는 4쪽에서 시작하고, 개인 프로젝트는 마지막 별도 페이지에 배치합니다.

서비스 캡처가 없는 자리는 **실제 화면 캡처 예정**으로 표시합니다. 캡처를 추가하면 번호 배경 대신 실제 이미지가 표시됩니다. 프로필 사진은 선택 사항입니다.

## 수정 후 확인

- 요약 PDF 3쪽 유지, 회사 상세 4쪽 시작, 문서 내부 링크 동작
- PDF의 제목·본문·도식 잘림과 불필요한 빈 페이지 여부
- 외부 요청을 차단한 상태에서도 폰트·도식 로딩
- 모바일 HTML에서 가로 넘침 여부

출력 명령과 이미지 추가 방법은 [편집 가이드](README.md)를 참고합니다.
