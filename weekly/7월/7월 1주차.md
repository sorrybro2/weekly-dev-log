# 주간 업무 회고 (7월 1주차)

## 1. 주요 업무 성과 (Key Achievements)

법무법인 홈페이지 V2의 보안·SEO를 컷오버 대비 수준으로 전면 강화하고, 신규 사건관리 앱의 상담료·수발신 문서대장 실사용 흐름을 구축했으며, CRM의 홈페이지 접수 PostgreSQL 포팅과 성능 병목을 해소한 고밀도의 한 주. 주 후반(7/3)에는 본사에서 홈페이지 V2를 공개하고 한국진흥교육원 정보보안 교육을 이수함.

- **법무법인 홈페이지 V2: 보안 전면 강화 및 SEO/AEO/GEO 구조화 데이터 도입**

    - **보안(FE/BE):**

        - 권한 없는 어드민에게 상담 개인정보(PII) 마스킹 적용해 노출 범위 최소화

        - 전역 보안 응답 헤더(클릭재킹·MIME 스니핑 방어) 추가, 상담 접수 API에 IP 기반 빈도 제한(throttle) 도입

        - 상담 폼 reCAPTCHA v3 봇 차단 연동 및 검증 강화(action 일치 검증·구글 검증 장애 시 fail-closed 전환)

        - 어드민 로그인을 Google 전용으로 일원화(이메일/비밀번호 폼 제거), 세션 만료 24h→12h 단축(활동 중 슬라이딩 갱신)

    - **SEO/AEO/GEO:**

        - AI 크롤러 허용(robots)·동적 사이트맵·조직/아티클/변호사 JSON-LD 도입, 생성형 엔진 안내용 `llms.txt` 추가

        - 뉴스 영역 URL을 쿼리 파라미터에서 경로 기반(`/news/media`·`/notice`·`/social`·`/video`)으로 개편하고 탭별 고유 메타데이터·사이트맵 반영

    - **뉴스/미디어:**

        - 동영상 소스를 YouTube Data API 우선(RSS 폴백)으로 전환·안정화, HTML 엔티티 디코딩 오류 수정, 전체 영상 페이지네이션·채널 구독 동선 추가

    - **승소 사례·UI:**

        - 변호사 프로필 사진 깨짐(스냅샷 경로 박제) 보정, 상세→목록 복귀 시 카테고리·검색 상태 유지

        - 성공사례 목차·본문 소제목을 게시글별로 직접 지정 가능하도록 개선(`steptitles` 컬럼·어드민 편집·기본값 폴백)

        - 어드민 카테고리 관리 개선(그룹 드롭다운·모바일 인라인 편집), 동영상 수기 관리 탭 제거, 헤더 가독성·채용 동선 정비

- **사건관리 앱(신규): 상담료 관리 페이지 개편 및 수발신 문서대장 구축**

    - **상담료(상담 관리):**

        - 목록/처리 대기를 좌·우 1:1 분할 동시 표시로 개편, CRM 방문상담 스케줄과 연동해 클릭 시 상담료 폼 자동 매핑(의뢰인·상담일·유형·상담변호사·메모)

        - 상태 필터·검색·페이지네이션·'모든 지사' 합산 조회 추가, 연월 선택 달력 드롭다운화, 상담자 역할(변호사/직원) 분리 필터·금액 콤마·사건명 컬럼·반응형 레이아웃 적용

    - **수발신 문서대장(신규):**

        - 전 사건 통합/단건 조회 API 구축(사무소·기간·구분·사건·키워드 필터), 목록·등록/수정 화면 신설

        - 필터 카드 UI·행 클릭 상세 드로어·페이지네이션·필터 localStorage 유지, 사건 선택 시 Drive 링크 자동 채움

    - **계약:**

        - 상세 패널에 폴더트리·수납내역·도과 로직 보강, 의뢰인명 조회 경로 보정 및 레거시 폴백 추가

- **CRM (고객관계관리 시스템): 홈페이지 접수 PG 포팅 및 성능·정합성 개선**

    - 홈페이지 상담 접수 기능을 PostgreSQL에서 동작하도록 포팅(테이블 DDL·보장 스크립트), 접수 대기 뱃지 카운트 로직 수정

    - 회생 폼 유입경로 메모 상시 입력, 회생 PDF·이미지 출력에서 민감 항목 제외

    - 날짜 범위 필터 오입력 시 500 오류 방어 및 시작/종료 역순 자동 보정

- **주요 이벤트 및 교육 (7/3)**

    - **홈페이지 V2 공개:** 본사에서 리뉴얼 홈페이지 V2를 공개(발표) — 한 주간 진행한 보안·SEO·구조화 데이터 정비 성과를 대내 공유

    - **정보보안 교육 이수:** 한국진흥교육원 정보보안 교육 참석, 실무 보안 강화 작업(PII 마스킹·빈도제한·reCAPTCHA 등)과 연계되는 보안 지식 습득

## 2. 기술적 도전 및 트러블슈팅 (Technical Challenges & Troubleshooting)

- **FDW foreign table JOIN 병목 제거(8초→0.05초):** 사건관리 앱 상담료 '처리 대기' 조회가 8초 소요되던 문제를, `crm.*`가 postgres_fdw foreign table임을 확인해 원격 푸시다운되지 않는 인라인 JOIN을 제거하고 스케줄 선조회 후 이름을 배치 조회하는 방식으로 전환하여 약 160배 개선함.

- **YouTube 동영상 연동 안정화:** RSS 피드가 데이터센터(서버) IP에서 구글에 차단돼 운영 동영상 탭이 간헐적으로 통째 비던 문제를, YouTube Data API 우선 호출 + 실패·쿼터 초과 시 RSS 폴백의 2단 재시도 구조로 재설계해 가용성을 확보함.

- **CRM 홈페이지 접수 MySQL→PostgreSQL 포팅:** MySQL 전제로 작성된 접수 기능이 PG 전환 후 동작하지 않던 문제를, 테이블 DDL·보장 스크립트와 서비스 로직을 PG 기준으로 포팅해 해소함.

- **당사자 시트 동기화 지연(~36초) 제거:** 당사자 생성·수정·삭제 시 구글시트 양방향 동기화가 응답 전 동기 await로 수행되며 발생하던 ~36초 지연을, 응답 후 백그라운드 실행으로 전환하고 제거됐던 CRM→시트 미러링을 복구해 근본 해소함.

- **변호사 프로필 이미지 스냅샷 박제 버그:** 사례 데이터에 작성 시점 이미지 경로가 스냅샷으로 박제돼 변호사가 사진을 교체하면 삭제된 옛 경로를 참조해 깨지던 문제를, 목록·상세 모두 현재 `tbl_lawyer` 프로필 이미지로 덮어쓰는 보정 로직으로 공통화해 해결함.

- **reCAPTCHA 검증 정책 강화:** 토큰 action 일치 검증(다른 동작용 토큰 재사용 차단)을 추가하고, 구글 검증 서버 장애 시 기존 통과(fail-open) 대신 기본 차단(fail-closed)으로 전환해 봇 방어의 신뢰성을 높임.

## 3. 총평 및 향후 과제 (Wrap-up & Next Steps)

> **"홈페이지·CRM·신규 사건관리 앱 3개 축을 동시에 밀며, 보안·SEO 정비와 대형 성능 병목 해소를 함께 끝낸 밀도 높은 한 주"**

법무법인 홈페이지 V2는 PII 마스킹·보안헤더·빈도제한·reCAPTCHA·Google 전용 로그인으로 보안을 컷오버 대비 수준까지 끌어올리고, AI 크롤러 허용·동적 사이트맵·JSON-LD·경로 기반 URL로 검색·생성형 엔진 노출 기반을 확립함. 병행하여 신규 사건관리 앱의 상담료 관리와 수발신 문서대장을 API부터 화면·필터·페이지네이션까지 실사용 흐름으로 구축하고, FDW JOIN 병목(8초→0.05초)과 당사자 시트 동기화 지연(~36초)이라는 대형 성능 문제를 근본 해소해 개발·운영 생산성을 크게 높임.
