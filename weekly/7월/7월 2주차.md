# 주간 업무 회고 (7월 2주차)

## 1. 주요 업무 성과 (Key Achievements)

법무법인 홈페이지 V2의 **도메인 컷오버 대비 SEO/AEO/GEO를 완성**하고 세로 모니터(포트레이트)까지 포함한 반응형을 전면 정비했으며, 신규 사건관리 앱에 **수발신 문서 결재 워크플로와 열람/등사 화면을 처음부터 구축**한 고밀도의 한 주. 주 전반(7/6~7/8)은 홈페이지 V2에, 주 후반(7/8~7/10)은 사건관리 앱에 집중했고, CRM은 브랜딩 교체와 연락처·직원 동기화 개선을 병행함.

- **법무법인 홈페이지 V2: 컷오버 대비 SEO/AEO/GEO 완성 및 세로 모니터 반응형 정비**

    - **SEO(도메인 컷오버 대비):**

        - 레거시 ASP.NET 주소(`/{지역}/wincasedetail?index=N`)를 V2 클린 주소(`/{지역}/cases/N`)로 301 이전(지역·ID 보존·쿼리 제거), 폐기 해외지사(vietnam·china)는 홈으로 301

        - 정본 호스트(www)가 아닌 테스트서버는 robots 전면 차단 + `X-Robots-Tag: noindex`, www 전환 시 자동 허용

        - 모든 페이지가 홈으로 canonical 되던 버그 제거(상세글은 지역 없는 자기 주소, 지사 페이지는 각자 자기 주소)

        - 2024년 옛 주소 2,328개 담긴 정적 sitemap 제거, 동적 콘텐츠 사이트맵을 표준 `/sitemap.xml`로 통합

    - **AEO/GEO(AI 검색·답변엔진 대비):**

        - 상세글 Article JSON-LD에 본문 전체(`articleBody`)·`dateModified` 추가, 전문센터 Center·법승TV VideoObject JSON-LD 신규 추가

        - 본사 LegalService에 공식 SNS(유튜브·인스타·페이스북·X·네이버블로그·카카오·네이버톡)를 `sameAs`로 연결하고 대표 주소·전화(NAP)를 지사 DB에서 주입(어드민 수정 시 자동 동기화)

        - 지사 10곳에 각 지사 네이버 플레이스를 `sameAs`로 부착(로컬 GEO), 칼럼·사례 저자를 담당 변호사 실명(Person)으로 귀속해 E-E-A-T 신호 강화

    - **세로 모니터(포트레이트) 반응형 전면 정비:**

        - 데스크탑 가로 레이아웃 분기점을 `lg`(1024px)→`xl`(1280px)로 올려 세로 모니터(폭 1024~1280px)에서 넘쳐 깨지던 문제 해소

        - 하단 상담 접수바를 전 페이지 공통 노출(어드민·전문센터 제외)하고 좁은 화면에선 4칸 dock으로 전환, 헤더·푸터·변호사 상세·회사소개 카드를 좁은 폭 기준으로 정리

        - 관리자 목록 표 11곳을 가로 스크롤로 전환, 히어로 영역은 세로 화면에서 높이 축소·중앙 정렬

    - **모바일 UX·상담 접수·성공사례·어드민:**

        - 모바일 하단바를 상담신청·카카오톡·네이버예약·전화상담 4칸 고정 dock으로 통합, 햄버거 메뉴를 단일 오픈 아코디언으로 개편

        - 상담 접수를 reCAPTCHA·카테고리 조회 병렬화 + CRM 전달 fire-and-forget으로 전환(콜드스타트 최대 4초 대기 제거), first-touch 유입경로 쿠키(24h)·서버 확정 IP 기록 추가

        - 숨김(`useflag='N'`) 변호사를 전 게시물에서 제외하고 성공사례는 노출 변호사 0명 시 담당 지역지사로 대체 표기, 변호사 상세 대표사례를 자동 캐러셀→정적 그리드로 전환

        - 변호사 편집 폼 강화(프로필 사진 업로드·직급 드롭다운·전문분야/자격 항목별 통합 입력), 어드민 단축 URL 관리·직급자격 관리 화면 제거해 운영 동선 일원화, 동영상 탭에 유튜브 채널 헤더 추가

- **사건관리 앱(신규): 수발신 문서 결재 워크플로 및 열람/등사 화면 구축**

    - **수발신 문서 결재 워크플로(신규):**

        - P1 — `document_logs`에 결재 컬럼(상태/승인자/코멘트/시각) 추가, 목록에 배지 + 대기/완료/보류 세그먼트 필터(레거시 행은 대상 제외)

        - P2 — 담당 변호사에게 결재요청 Gmail 발송 + 서명토큰 기반 무인증 원클릭 결재 페이지(수락/거절/코멘트)

        - P4 — 헤더 알림 벨·뱃지·30초 폴링·토스트 + 로그인 상태 인앱 결재(알림은 승인자에게만·미처리 건만)

        - 문서 등록 시 결재요청 자동 발송(best-effort), 흩어져 있던 상세 모달·폼페이지를 전역 드로어 하나로 통합(-1139/+382)

    - **열람/등사(record-requests) 화면(신규, 화면 7·8):**

        - 목록(월·사무소·상태·도과 필터)과 등록/수정(좌측 sticky 4섹션 폼, 재알림일 실시간 미리보기·사건 선택 시 이메일 자동 채움) 신설, 목록 API에 기간·사무소 필터·사건명/담당자 조인 추가

## 2. 기술적 도전 및 트러블슈팅 (Technical Challenges & Troubleshooting)

- **canonical 홈-상속 버그 제거:** 모든 페이지가 홈 주소로 canonical 되어 상세글·지사 페이지가 색인 경쟁에서 홈에 흡수되던 문제를, 상세글은 지역 없는 자기 주소·지사 페이지는 각자 자기 주소로 위임하는 하이브리드 규칙으로 정리함.

- **정적 sitemap 2,328건 크롤 낭비 제거:** 2024년 옛 주소 2,328개가 담긴 정적 sitemap이 컷오버 후 전부 301 대상이 되어 크롤 낭비·경고를 유발할 문제를, 정적 파일을 삭제하고 동적 `/sitemap.xml`(항상 현재 V2 200·canonical 일치)로 통합해 선제 해소함.

- **세로 모니터 레이아웃 넘침(lg→xl 분기 재설계):** 데스크탑 가로 레이아웃 분기점이 `lg`(1024px)여서 실제로는 ~1280px 이상이 필요한 레이아웃이 세로로 세운 모니터(폭 1024~1280px)에서 넘쳐 깨지던 문제를, 분기점을 `xl`(1280px)로 올려 그 구간은 좁은 화면 레이아웃으로 안전하게 흐르도록 통일함.

- **대시보드 집계 0 버그 2건:** 데이터는 `전화 상담(직원)`(공백 포함)인데 비교 상수는 `전화상담`(공백 없음)이라 매칭 실패로 상담·방문이 0이던 문제를 공백 정규화로, `contract_ym`이 CHAR(6)에 연도만(`'2025  '`) 저장돼 월별 계약이 0이던 문제를 계약일 기준 `YYYYMM` 재설정 마이그레이션(525건 적용)으로 각각 해결함.

- **Gmail 발송 로그 cp949 인코딩 오탐:** 발송 로그의 `→`·`—` 문자가 Windows cp949 콘솔에서 `UnicodeEncodeError`를 일으켜 실제로는 발송 성공인데 실패(ok=false)로 잡히던 오탐을, 로그를 ASCII로 바꿔 해결함.

- **크롤러 캘린더싱크 트리거 404:** 크롤러 6단계 트리거가 Cloud Run Jobs v1(잘못된 리소스 경로)을 호출해 매번 404로 실패하던 버그를 v2 API로 수정하고, 7태스크가 각자 보내던 완료 리포트를 완료신호 카운터 + 원자적 선점으로 통합해 1회만 발송하도록 재설계함.

- **답변엔진의 법인 엔티티 혼동 대비:** 답변엔진(Perplexity·Gemini·네이버 CUE 등)이 "법승"을 별개 로펌과 혼동하는 문제를 확인해, 법인·지사 스키마에 공식 SNS·네이버 플레이스(`sameAs`)와 대표 NAP를 심어 컷오버 이후 AI가 읽을 엔티티 식별 근거를 선제 확보함.

## 3. 총평 및 향후 과제 (Wrap-up & Next Steps)

> **"홈페이지 컷오버 대비 SEO·반응형을 마무리하는 한편, 사건관리 앱에 결재·열람등사 두 개의 신규 워크플로를 처음부터 세운 한 주"**

법무법인 홈페이지 V2는 레거시 URL 301 이전·테스트서버 색인 차단·canonical 정리·동적 sitemap 통합·JSON-LD 엔티티 결속(sameAs·NAP·저자 E-E-A-T)으로 도메인 컷오버 시 검색·답변엔진이 읽을 재료를 완성했고, 데스크탑 분기점을 `xl`로 올려 세로 모니터에서도 안 깨지는 반응형과 모바일 상담 dock·메뉴 아코디언까지 정비함. 병행하여 신규 사건관리 앱에는 수발신 문서 결재 워크플로(P1 상태→P2 이메일 원클릭→P4 인앱 알림)와 열람/등사 화면(공휴일 반영 영업일 자동 독촉)을 API부터 화면·알림까지 실사용 흐름으로 구축하고, 대시보드 집계 0 버그·크롤러 트리거 404 같은 운영 문제를 함께 해소해 앱의 완성도를 크게 끌어올림.

**향후 과제:**

- **홈페이지 V2 도메인 컷오버:** 이번 주 완성한 SEO/AEO/GEO 정비분이 실제 색인·노출로 발동되도록 www.lawwin.co.kr 정식 전환 진행(현재는 테스트서버 색인 차단 상태로 대기)

- **reCAPTCHA 운영 전환:** 검증 강화·배포는 완료, 운영 사이트키 발급·시크릿 설정 시점 확정 필요

- **사건관리 앱 화면 확장:** 결재·열람등사에 이어 미수금 등 잔여 화면 순차 구축, 결재/독촉 이메일·인앱 알림의 실사용 검증

- **CRM 운영 컷오버:** 홈페이지 상담 접수 forward를 테스트 CRM에서 운영 CRM으로 전환
