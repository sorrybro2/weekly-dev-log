# 주간 업무 회고 (6월 1주차)

## 1. 주요 업무 성과 (Key Achievements)

CRM 데이터 추출 기능 고도화 및 리뉴얼 홈페이지의 신규 어드민(CMS) 인프라 구축, 마케팅 트래킹 최적화 달성

- **CRM: 데이터 비식별 추출 및 편의성 고도화**
    
    - **데이터 추출 및 외부 연동:**
        
        - 상담/당사자 목록 유입내역 데이터 엑셀, CSV, 구글시트 추출 기능 통합
            
        - 다운로드 시 개인정보(성함, 전화번호) 비식별(마스킹) 자동 처리 적용
            
        - 추출 항목 커스텀 기능 및 드래그 앤 드롭 방식의 컬럼 정렬 UI 적용
            
        - 구글 OAuth 연동을 통한 드라이브 권한 획득 및 Refresh Token 암호화 저장 로직 구현
            
    - **사용성 및 보안 강화:**
        
        - 공용 필터에 연/월 드롭다운 자동 날짜 범위 설정 기능 도입
            
        - 직원 검색 조건에 내선번호(extension_number) 매칭 기능 추가
            
        - 본인 소속 사무실 데이터 조회 권한 로직 및 추출 내역 감사 로그(Audit Log) 추적 적용
            
- **법승 메인 홈페이지: 마케팅 트래킹 정밀화**
    
    - **전환 데이터 수집 개선:**
        
        - 액션별(카톡, 톡톡, 예약 등) 네이버 전환 유형 개별 연결 및 노이즈(퀵메뉴 등) 수집 제외 처리
            
        - 메인 상담 폼과 서브 연락처 페이지의 전환 이벤트를 명확히 분리하여 수집
            
- **홈페이지 리뉴얼: 대규모 관리자(Admin) 시스템 구축 및 UI 적용**
    
    - **프론트엔드 및 인터랙션:**
        
        - 소개/전문센터 페이지 다크 시네마틱 캔버스 테마 개편 및 3D 틸트, 패럴럭스, 마퀴 애니메이션 적용
            
        - 하단 상담바 실제 DB 연동 및 전화번호 역매핑 기반의 담당 지사 자동 배정 로직 구현
            
    - **콘텐츠 관리 시스템(CMS) 고도화:**
        
        - 자동 예약 발행 시스템(도래 전 404 차단) 및 컨텐츠 타입별 맞춤형 작성 폼 구축
            
        - 어드민 게시판 커서 튐 현상 해결, 미니 툴바 서식 편의성 추가 및 지사별 소속 변호사 필터링 연동
            
        - 게시글 노출 상태(노출/예약/숨김) 단일 버튼 통합 및 로컬 디스크 저장(GCS 전환 대비 저장소 추상화) 기반 자체 이미지 업로드 시스템 구축
            
    - **인사 및 운영 인프라 구축:**
        
        - 최고관리자(SA) 전용 계정/직급 관리 구축 (자체 이메일 로그인 연동, 순서 드래그 정렬)
            
        - 전문센터, 상담 접수 관리 필터링 및 단축 URL 생성/측정(비정상 리다이렉트 차단) 기능 적용
            

## 2. 기술적 도전 및 트러블슈팅 (Technical Challenges & Troubleshooting)

- **마케팅 전환(GTM) 중복 수집 이슈 해결:** 인라인 호출과 스크립트 호출이 동시에 발동되던 구조를 정리하여 중복 집계 오류를 소스 레벨에서 원천 차단하고, 페이지 로드당 1건만 집계되도록 방어 로직을 적용함
    
- **구글 API 연동 토큰 저장 기준 변경:** 구글시트 저장 오류의 원인을 파악하여, OAuth 토큰 저장 방식을 기존 사원 키(employee_key)에서 '이메일' 기준으로 변경함으로써 연동 실패 문제를 완벽히 해결함
    
- **프론트-백엔드 세션 만료 시간 동기화:** 프론트엔드(4시간)와 백엔드 JWT(8시간) 간의 만료 시간 불일치로 인한 강제 로그아웃 문제를 8시간으로 연장 동기화함. 어드민 시스템은 문서 작업 편의를 고려하여 마지막 활동 기준 24시간 롤링 세션으로 개편함
    
- **어드민 실시간 데이터 연동 이슈:** 관리자 페이지에서 게시글, 변호사 정보 등을 수정 시 공개 홈페이지에 즉시 반영되지 않던 캐시 문제를 해결하여 실시간 동기화 안정성을 확보함
    
- **스크롤 최적화 라이브러리 충돌 롤백:** 스무스 스크롤(Lenis) 도입 중 개발 환경 핫리로드 잠김 및 100% Height 레이아웃 충돌 이슈가 발생하여, 시스템 안전성을 우선하여 브라우저 기본 스크롤로 안전하게 롤백함
    

## 3. 총평 및 향후 과제 (Wrap-up & Next Steps)

> **"보안이 강화된 데이터 파이프라인과 높은 완성도의 통합 관리자 시스템을 구축해 낸 한 주"**

CRM 시스템에 개인정보 비식별화 및 구글 시트 직접 연동을 도입하여 보안과 업무 효율을 동시에 잡았습니다. 또한, 레거시 메인 홈페이지의 마케팅 데이터 정합성을 개선하고, 신규 리뉴얼 사이트의 대규모 어드민 및 CMS 고도화를 안정적으로 배포 대기 상태로 이끌어내어 향후 효율적인 콘텐츠 운영 기반을 마련했습니다.

**향후 과제:**

- **어드민 이메일(SMTP) 발송 연동:** 관리자 시스템 내 추가된 이메일 발송 화면 및 검증 로직에 실제 SMTP 서버 설정을 연동하여 발송 기능 완성 예정
    
- **외부 마케팅 태그 잔존 여부 점검:** 전환 중복 수집 방어 로직은 적용 완료하였으나, GTM 등 외부 툴의 잔존 태그로 인한 사이드 이펙트 가능성 별도 점검 예정
