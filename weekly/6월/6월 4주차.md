# 주간 업무 회고 (6월 4주차)

## 1. 주요 업무 성과 (Key Achievements)

주 초반(6/22~24)은 법무법인 홈페이지 V2의 이미지 인프라·어드민 인증 고도화와 CRM의 MySQL → PostgreSQL 마이그레이션 컷오버 준비, 신규 사건관리 앱 기반 구축에 집중하고, 주 후반(6/25~26)은 Legal AX Summit 참석으로 리걸테크 동향을 파악함.

- **법무법인 홈페이지 V2 리뉴얼: 이미지 서빙 GCS 전환, 어드민 Google Workspace 인증 일원화, 전문센터 확장**

    - **이미지 서빙 및 폴백 정비:**

        - 이미지 서빙을 레거시 가비아 프록시에서 **GCS 기준으로 전환**하고, 이관 과정에서 발생한 공지·사회공헌 이미지 미표시 라우팅 버그 수정

        - 게시판 카드·홈 미디어 컬럼의 썸네일 결손·깨짐 시 **대표 변호사 사진으로 폴백** 통일 (이후 로고 플레이스홀더 방식으로 정리)

    - **어드민 인증·관리 강화:**

        - **Google Workspace 역할 기반 어드민 인증(읽기)** 도입 및 기존 방식과의 하이브리드 폴백 적용, 계정 관리를 Workspace 기준으로 일원화

        - 슈퍼어드민 전용 직원 권한 부여/회수 화면, 변호사 신규 등록, 컨텐츠 목록 상단 고정, 모바일 반응형 셸(햄버거 드로어) 구현

    - **컨텐츠·UI 정비 및 배포:**

        - 소년·학폭 전문센터 신규 추가(**전문센터 7개** 기준 카운트·바로가기 보정), 홈 미디어 컬럼 카테고리 연결·인증마크·타이포 정비

        - 상담 게시판 표 폭·한글 세로 쪼개짐, 대표 변호사 사진/카드틀 등 UI 다수 정비, Cloud Build **Kaniko 레이어 캐시 전환**으로 빌드 시간 단축

- **CRM (고객관계관리 시스템): MySQL → PostgreSQL 마이그레이션 컷오버 준비 및 실무 개선**

    - **DB 마이그레이션(주간 핵심):**

        - DB 드라이버를 MySQL → PostgreSQL로 교체하고 호환 래퍼로 기존 코드 동작 보장(스모크 테스트 통과)

        - SQL 방언을 다차수로 체계적 변환(함수·날짜·따옴표 → UPSERT·락·대소문자 → LIMIT/OFFSET, `DATABASE()` → `current_schema()`)

        - MySQL→PG 데이터 마이그레이터 및 컷오버용 증분 UPSERT 동기화 스크립트 추가, prestart를 PG 스키마 확인으로 교체

    - **컷오버 준비 및 실무 버그:**

        - 회생팀 전용 발신번호 추가, NULL 일자 레코드 정렬, 회생 상담관리 목록·상태 배지·페이지네이션, 당사자 수정/삭제 지연 및 담당자 표시 버그 수정

- **사건관리 앱(신규): 상담료 관리 시스템 및 사건·계약 화면 구축, PostgreSQL FDW 연동** *(git log 기준)*

    - 상담료 관리 시스템 구현 및 프론트엔드 기반 작업 착수

    - 사건 목록/상세, 계약 목록/상세 UI 구현

    - PostgreSQL **FDW(crm 스키마) 설정** + 레거시 데이터 마이그레이션 + `bs` → `crm` 코드 전환

- **외부 활동: Legal AX Summit 참석 (6/25~26)**

    - 리걸테크·법률 AI 트랜스포메이션 동향 파악 및 실무 적용 인사이트 수집

## 2. 기술적 도전 및 트러블슈팅 (Technical Challenges & Troubleshooting)

- **CRM DB 스택 전면 이관(MySQL → PostgreSQL):** 운영 DB 이전을 위해 드라이버 교체 후 MySQL 전용 문법을 다차수로 PG 방언 변환하고, 데이터 마이그레이터와 컷오버 시점 반영용 증분 UPSERT 동기화 스크립트를 구축함. 테스트 서버 배포·검증으로 읽기 엔드포인트 QA 11/11을 통과시켜 컷오버 직전 상태까지 안정화함.

- **이미지 인프라 GCS 전환 및 라우팅 정합:** 레거시 가비아 프록시 의존을 GCS 서빙으로 걷어내는 과정에서 발생한 이관 이미지 미표시 문제를 경로 매칭 수정으로 해결하고, 썸네일 폴백 정책을 일관되게 정리함.

- **어드민 인증 체계 전환(Google Workspace 기반):** 이메일/비밀번호 계정의 수기 관리 문제를 해소하기 위해 Workspace 역할 기반 인증을 도입하되, 하이브리드 폴백을 두어 무중단으로 안전하게 전환함.

- **당사자 처리 지연(~36초) 해소:** 당사자 수정/삭제 시 CRM→구글시트 동기화가 동기적으로 수행되며 발생하던 약 36초 지연을 해당 동기화 제거로 근본 해소함.

- **사건관리 앱 CRM 연동(FDW) 및 마이그레이션:** PostgreSQL FDW로 `crm` 스키마를 연동하고 레거시 데이터를 이관하며 `bs`→`crm` 코드 전환 및 마이그레이션 버그를 정리함.

- **정렬·표시 결함 정리:** 상담일자·`created_at`이 NULL인 레코드가 목록 최상단에 노출되던 정렬 문제, 담당자가 이름 대신 내부 키로 표시되던 문제 등 실무 표시 버그를 수정함.

## 3. 총평 및 향후 과제 (Wrap-up & Next Steps)

> **"홈페이지·CRM·신규 사건관리 앱 3개 축을 동시에 진전시키며, CRM DB 이관을 컷오버 직전까지 끌어올린 고밀도의 한 주"**

법무법인 홈페이지 V2의 이미지 인프라와 어드민 인증을 구조적으로 개선하여 운영 안정성과 관리 편의성을 동시에 확보함. 특히 CRM의 MySQL → PostgreSQL 마이그레이션을 드라이버 교체부터 방언 변환·데이터 이관·컷오버 런북·QA까지 체계적으로 완성해, 신규 데이터 스택으로의 전환 기반을 확립함. 병행하여 신규 사건관리 앱의 프론트엔드 골격과 CRM(FDW) 연동을 구축해 후속 개발의 토대를 마련함.

**향후 과제:**

- **CRM PostgreSQL 컷오버 실행:** 확정된 컷오버 명령·런북을 기반으로 본 서버(lawwin-crm) 실제 전환 수행 및 잔여 Phase 검증 마무리

- **사건관리 앱 화면 확장:** 상담료·사건·계약에 이어 미수금·열람/등사·문서대장 등 잔여 화면 순차 구축

- **홈페이지 V2 마무리:** 어드민 Google Workspace 인증의 쓰기 권한 확장 및 컨텐츠·리소스 현행화
