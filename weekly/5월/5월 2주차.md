# 주간 업무 회고 (5월 2주차)

## 1. 주요 업무 성과 (Key Achievements)

CRM 시스템 v1.0 정식 배포 완료 및 SMS·공지사항 기능 고도화, 회생 상담 도메인 연동 성공

- **사내 CRM 시스템: 정식 오픈 및 v1.0.1 ~ v1.0.2 기능 고도화, 회생 상담 연동**
    
    - **릴리즈 및 서비스 오픈:**
        
        - 운영 환경 정식 배포 성공 및 사용자 설명회 자료/일정 구성 완료.
            
        - v1.0.1 및 v1.0.2 릴리즈 버전 제반 기능 병합 완료.
            
    - **UI/UX 및 프론트엔드 (FE):**
        
        - 공지사항 알림 배지 및 플로팅 애니메이션(말풍선) 사이드바 적용, 화면 분할(목록/상세) 구조 개편 완료.
            
        - SMS 양식 목록 세로형 그리드 및 토글 버튼 도입, 다중 이미지(최대 3장) 드래그 앤 드롭 첨부 기능 구현.
            
        - 회생 상담 화면(목록/상세/등록) 신규 구축 및 당사자 정보(성명, 연락처 등) 자동 채우기(Prefill) 적용.
            
        - 입력 폼, 상세 페이지, CSV 목록 간 데이터 항목 및 라벨 1:1 매핑하여 UI 정합성 확보.
            
        - 웹/비웹 환경 분기 처리 및 브라우저 인쇄·저장 다이얼로그(layoutPdf)를 활용하여 회생 상담일지 PDF 출력 및 저장 기능 구현 완료.
            
    - **백엔드 및 DB/인프라 (BE/Infra):**
        
        - 지사 공통 양식 기준을 조직 단위(organization_key)에서 발송번호(sender_key) 단위로 전환.
            
        - `recovery_intake` 테이블 신규 생성, CRUD 및 Soft-delete API 구현.
            
        - 트랜잭션 로직 적용: 당사자 데이터 삭제 시 연결된 회생 상담 내역 일괄 삭제 처리.
            
        - 구글 시트(문자, 당사자) 데이터를 Cloud SQL로 일괄 마이그레이션 및 제주지사 조직 기본값 조정.
            
    - **문서화 및 환경 설정 (Docs & Env):**
        
        - Cloud SQL Auth Proxy 활용 데이터 적재 가이드 작성.
            
        - FE/BE 통합 빌드 가이드 및 Git 커밋 규칙 표준화 문서 배포.
            
        - 플랫폼(Linux, macOS, Windows)별 플러그인 등록 파일 동기화로 타 환경 빌드 노이즈 방지.
            

## 2. 기술적 도전 및 트러블슈팅 (Technical Challenges & Troubleshooting)

- **SMS 이미지 다중 첨부 및 호환성 보장:** 웹 환경 파일 드래그 앤 드롭 처리 안정화 및 3장 초과 시 업로드 차단 방어 로직을 구현함. 동시에 기존 단일 사진 데이터와의 하위 호환성을 유지하도록 설계함.
    
- **데이터베이스 정합성 및 마이그레이션:** SMS 양식 DB 스키마 업데이트(식별용 컬럼 및 인덱스 추가)를 진행하고, 분산된 마케팅 지사 양식을 통폐합하여 Cloud SQL로 안전하게 마이그레이션함.
    
- **외부 API 연동 예외 처리 (구글 주소록 폴백):** 회생팀 당사자 등록 시 모바일 공용 계정 부재 상황을 대비하여, 특정 담당자(팀장) 계정으로 연락처가 자동 동기화되도록 Fallback(폴백) 안전장치를 마련함.
    
- **PDF 출력 환경 파편화 해결:** `printing`, `pdf` 패키지 도입 후 한글 폰트(Pretendard) 임베딩을 통해 문서 깨짐 현상을 방지함. 웹과 비웹(App) 환경 분기 처리 및 디버깅용 시간 추적 로그를 적용하고, 브라우저 인쇄 다이얼로그 연동을 통해 웹 환경에서도 안정적인 PDF 저장 및 출력이 동작하도록 문제를 해결함.
    

## 3. 총평 및 향후 과제 (Wrap-up & Next Steps)

> **"CRM 시스템의 성공적인 정식 런칭과 함께, 사용자 편의성 극대화 및 신규 회생 도메인 확장을 이뤄낸 밀도 높은 한 주"**
